# Team Video Analysis — Tracker parity v13

Основной редактируемый файл:
`team_video_analysis_unified.dart`

Остальные короткие `.dart` в папке — compatibility bridges и должны оставаться без дублирования кода.

## Что изменено

### VideoMatchReviewScreen
- Убран обязательный landscape для основного профессионального видеоразбора.
- iPhone/Android portrait теперь используют тот же адаптивный workspace.
- На узком экране TTD / Игроки / Эпизоды / AI открываются под видео, а не ужимаются справа.
- Добавлена отдельная вкладка `Карта`.
- Карта использует те же AI-треки, что overlay на видео.
- Добавлен режим `3D PRO / 2D`.
- 3D-камера: orbit, tilt, zoom, reset.
- Слои: маршрут, heatmap, сеть передач, средние позиции.
- Добавлена отдельная навигация `Разбор`.
- Тактический чертёж работает поверх видео и поверх 3D-карты.
- На 3D-карте рисунки находятся внутри той же transform-сцены и поворачиваются вместе с полем.
- Цветовая система синхронизирована с Tracker CMR: #00A750, #F3FAF6, #F7F8F7, #E9ECEA, #0B0F14, #5F6670.
- Основная поверхность видео сделана плоской, без лишней рамки/тени «карточка в карточке».

### TeamVideoAnalysisScreen / Overview
- Mobile breakpoint поднят до 760 px.
- KPI-блоки сделаны плоскими CMR-поверхностями без внешних теней.
- Основные панели обзора больше не выглядят отдельными карточками с рамками/тенями.
- Ключевая типографика переведена на `AppTypography` / `_VideoT`.

### CmrVideoAnalysisPanel
- Mobile breakpoint поднят до 760 px, чтобы iPhone/узкие планшеты раньше переходили в компактный режим.
