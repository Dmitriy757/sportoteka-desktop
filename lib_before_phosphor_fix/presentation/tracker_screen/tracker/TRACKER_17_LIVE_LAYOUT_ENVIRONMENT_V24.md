# Tracker 17 Live layout/environment v24

Изменения:

- Все верхние KPI имеют одинаковую высоту, включая «Нагрузка» и «AI индекс».
- «Спринты» оформлены так же, как «Бег» и «Ходьба»: крупное значение, показатели и нижняя полоска.
- Отдельный чип «Онлайн …» рядом с местом и погодой удалён. Длительность остаётся в KPI.
- Время Live обновляется локально каждую секунду по `started_at`, а не ждёт запаздывающий серверный счётчик.
- При получении реальной GPS-точки личной тренировки приложение вызывает `player_update_session_environment.php`.
- Место и погода обновляются сразу по первой координате, затем не чаще раза в 10 минут либо после перемещения более чем на 300 м.

Важно: координаты для environment сейчас берутся из подключённого GPS-трекера игрока. Одного разрешения геолокации iPhone недостаточно для Polar-only тренировки: для этого в основном проекте необходимо подключить получение координат телефона (например, через geolocator) и вызвать тот же API.
