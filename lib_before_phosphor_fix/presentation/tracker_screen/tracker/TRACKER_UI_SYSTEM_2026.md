# Sportoteka Tracker UI System 2026

## Единая структура
- Белый основной фон на Live, аналитике, отчётах, сессиях, устройствах и личных тренировках.
- Фирменный зелёный `#00A750` используется только для активного состояния, запуска, подтверждения и ключевых данных.
- Графитовый текст `#111512`, вторичный `#6B746E`, разделители `#E9ECEA`.
- Карточки без тяжёлых теней; структура создаётся тонкими линиями и отступами.
- Базовое скругление карточек 14 px, внутренних элементов 10 px, модальных окон 16 px.

## Навигация
- Текстовые вкладки и тонкая зелёная линия активного раздела.
- На мобильном: компактная шапка, постоянная нижняя навигация, контент до краёв экрана.
- На планшете/ПК: единое окно, боковая навигация и рабочая область без разных визуальных тем.

## Разделы
1. Dashboard — компактная сводка и готовность команды.
2. Live — старт, состояние сессии, игроки, Polar/GPS и поле.
3. Аналитика — единые фильтры, обзор, карта, скорость, пульс, рейтинги.
4. Активность — карта и временная линия в общей геометрии.
5. Сессии — выбор тренировки и детали без тяжёлых карточек.
6. Устройства — назначение игрок ↔ GPS/Polar в одном визуальном шаблоне.
7. Отчёты — мобильный, планшетный и ПК-вид используют одинаковую иерархию.
8. Личные тренировки — календарь, уведомления и детали в общей системе.

## Сохранено
BLE, Polar, GPS, API, session_id, фильтрация, отчёты, экспорт и серверная логика не изменялись.
