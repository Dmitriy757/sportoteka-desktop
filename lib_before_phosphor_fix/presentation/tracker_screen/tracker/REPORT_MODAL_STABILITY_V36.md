# Отчёты v36 — стабильное модальное окно

- «Применить» сохраняет выбранных игроков и блоки, но больше не закрывает окно.
- PDF и Excel открываются поверх выбора отчёта в отдельном окне; основной выбор остаётся открытым.
- Живой предпросмотр заменён на адаптивную вертикальную компоновку без жёсткой двухколоночной сетки.
- KPI используют Wrap, карты и графики получают безопасную высоту, поэтому устранены массовые RenderFlex overflow.
- Предпросмотр использует единые белые карточки, зелёный акцент, размеры и типографику аналитики.
