# Report / Calendar / Maps V22

- Календарь отчётов визуально приведён к карточному формату календаря аналитики.
- Для каждой сессии число игроков догружается из полного training report, а не определяется только по одной строке sessions API.
- В строке сессии основным заголовком остаётся название тренировки; технический badge с ID убран.
- При выборе сессии список выгрузки продолжает строиться только из участников отчёта выбранной сессии.
- Тепловая карта теперь агрегирует точки по мелкой сетке и рисует мягкую плотность вместо больших отдельных кругов.
- Точки маршрута и ореолы уменьшены, цифровые подписи скорости с карты убраны.
- В экранной и печатной HTML-карте используется одинаковая компактная логика плотности.
- Технические счётчики GPS/heat убраны из заголовка карты отчёта.

Важно: нативная выгрузка PDF использует серверный export_training_report_pdf.php. Для полного совпадения нативного PDF с новым HTML-шаблоном серверный PHP-шаблон должен использовать ту же сеточную агрегацию heatmap.
