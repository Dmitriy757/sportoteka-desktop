# Sportoteka UI Kit 2026

## Принцип
Одна белая рабочая поверхность. Крупные разделы не оформляются карточками.

## Токены
- Цвета: `STColors`
- Отступы: `STSpace` (2, 4, 8, 12, 16, 24, 32)
- Радиусы: `STRadius` (0, 8, 12, 16)
- Типографика: `STText`
- Анимации: `STMotion`

## Компоненты
- `STSection` — секция с тонким разделителем
- `STMetric` — KPI без карточки и иконки
- `STStatus` — Polar/GPS/Live как цветная точка и текст
- `STTabs` — текстовые вкладки с зелёной линией
- `STSearch` — поиск без рамки
- `STActionButton` — основная/вторичная/опасная кнопка
- `STEmptyState` — пустое состояние без декоративной иконки

## Правила
1. Без теней у рабочих разделов.
2. Без `Border.all` у крупных поверхностей.
3. Скругления только у контролов, кнопок и модалок.
4. Зелёный только для активного состояния и главного действия.
5. Иконки не используются в KPI и заголовках разделов.
