SPORTOTEKA — командный Live v55

Что исправлено

1. Командный экран больше не выбирает первого игрока состава автоматически.
   Арсений Берёзкин появлялся потому, что API возвращал его первым, а клиент
   выполнял _selectedPlayer = _players.first.

2. После назначения GPS выбор игрока очищается. Перед вторым GPS нужно явно
   выбрать следующего игрока.

3. Если у выбранного игрока уже есть другой GPS, клиент блокирует молчаливую
   замену и не снимает прежнюю привязку.

4. Повторный «Поиск GPS» больше не выполняет BLE RESET. Уже открытые командные
   каналы остаются подключёнными.

5. Шапка, список устройств, Live и debug теперь берут состояние из
   многоканального TeamActionTrackerBlePool, а не из старого одиночного BLE.

6. Каждому UUID по-прежнему соответствует отдельный ActionTrackerBleService.
   Ошибка одного нового подключения очищает только этот канал и не затрагивает
   уже подключённые GPS.

Как заменить

Распакуйте архив в корень Flutter-проекта с заменой файлов:
lib/presentation/tracker/...

PHP и SQL для этого клиентского исправления менять не требуется.

Правильный порядок подключения

1. Откройте «Датчики».
2. Нажмите «Поиск GPS» один раз.
3. Выберите игрока.
4. Нажмите его GPS-трекер.
5. После сообщения об успешной привязке выберите следующего игрока.
6. Повторите для всех GPS.
7. В Live должно отображаться «GPS подключено: N».
8. Нажмите «Старт».

Кнопка «Сбросить все GPS» остаётся отдельной явной операцией и действительно
останавливает/закрывает все командные BLE-каналы.
