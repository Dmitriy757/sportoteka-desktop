СПОРТОТЕКА — Flutter командный Live v51

Заменить папку tracker в проекте с сохранением её штатного расположения.
Серверную папку tracker из отдельного архива необходимо обновить одновременно.

Что исправлено:
- одна кнопка запускает все подключённые GPS команды;
- отдельный BLE-канал и live_session_id используются для каждого игрока;
- при ошибке одного трекера не остаётся частично запущенная тренировка;
- Polar H10 сохраняет пульс именно в Live-сессию своего игрока;
- передаются заряд, UUID и имя каждого GPS;
- алиасы MAC/iOS UUID одного $ATP не считаются разными физическими трекерами.
