SPORTOTEKA TRACKER — TEAM LIVE V62

Изменён файл:
- tracker_live_panel.dart

Что изменено:
1. Командный Live приведён к лёгкому флагманскому стилю CMR:
   - централизованный AppTypography / Inter;
   - мягкие зелёные и серые поверхности;
   - активные кнопки выделены заливкой;
   - у переключателей и служебных кнопок убраны тяжёлые обводки.
2. Переключатель «Игрок / Команда» стал явным сегментированным контролом.
3. В режиме «Команда» правая панель теперь показывает данные по всем
   отмеченным игрокам, а не только по последнему игроку в фокусе.
4. Добавлены три графических режима командной панели:
   - Пульс — отдельная линия каждого выбранного игрока;
   - Нагрузка — сравнительные полосы по игрокам;
   - Скорость — отдельная линия скорости каждого игрока.
5. Добавлен индикатор «Командные данные собираются»:
   - число выбранных и online-игроков;
   - покрытие GPS X/N;
   - покрытие Polar H10 X/N.
6. На общей карте появилась горизонтальная легенда выбранных игроков:
   - цвет точки игрока;
   - текущая скорость;
   - текущий пульс.
7. Командные показатели рассчитываются только по игрокам, отмеченным
   в режиме «Команда»:
   - пульс сейчас — среднее актуальных H10 значений не старше 35 секунд;
   - средний и максимальный пульс — по live-истории выбранных игроков;
   - скорость — средняя текущая скорость игроков с GPS;
   - максимальная скорость — максимальное значение выбранной группы;
   - дистанция, HIR, спринты, ACC/DEC — сумма по выбранным игрокам;
   - нагрузка — среднее и пик GPS load_score выбранной группы.
8. Поле и командная панель остаются рядом 50/50 на ПК и планшете.

BLE-координатор, привязки устройств, запуск/остановка командной сессии,
серверные эндпоинты и схема базы данных не изменялись.
