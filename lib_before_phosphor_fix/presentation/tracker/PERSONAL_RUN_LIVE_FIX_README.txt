ЛИЧНЫЕ LIVE-ТРЕНИРОВКИ — РЕЖИМ «БЕГ»

Исправлено:
- скорость Live восстанавливается по GPS-расстоянию и времени, если трекер
  прислал speed=0;
- «Бег / Ходьба / Спринты» рассчитываются и отправляются до завершения сессии;
- пороги: бег от 7 км/ч, спринт от 18 км/ч;
- GPS обновляется примерно раз в 3 секунды, Live-сводка — раз в 5 секунд;
- одиночные невозможные GPS-скачки не рисуют диагональ и не создают ложный спринт;
- для outdoor_run используется отдельная карта маршрута вместо футбольного поля;
- на экране игрока добавлены текущий темп, скорость, процент бега и спринты;
- увеличена высота верхних карточек, чтобы убрать RenderFlex overflow.
- модель TrackerLivePointPayload синхронизирована с экраном: добавлены поля
  runDistanceM, walkDistanceM, длительности и проценты движения.

SQL и изменения PHP не требуются.
