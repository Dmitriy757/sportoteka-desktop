# Исправление пустого Live-экрана

Причина: в мобильной/узкой раскладке блок управления Live был внутри `ListView` без фиксированной высоты, а внутри него был `Expanded`. Flutter получал unbounded height и мог показывать пустой экран/ошибку layout.

Исправлено:

```dart
SizedBox(height: 560, child: _controls(online, active.length))
```

Также добавлены:
- стартовый лог `Live открыт...`;
- явная проверка разрешений геолокации;
- первая GPS-точка отправляется сразу после старта, а не через секунду.
