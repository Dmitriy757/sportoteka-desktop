# Функции, найденные в actiontracer.apk

APK содержит приложение ACTIONTRACER / TraceTrainer на базе .NET MAUI / Blazor Hybrid.

Найдены функции:

```text
ScanBluetoothDevice
ConnectBluetoothDeviceByUUID
DisconnectAllBluetooth
SendDevicePowerOrder
SendCurrentGPSOrder
SendCurrentHistoryListOrder
SendCurrentHistoryOrder
SendCurrentHistoryCompressOrder
SendAllHistoryOrder
SendAllHistoryCompressOrder
ClearDeviceHistoryByUUID
ReadFixTTResultById
ReadFixTTResults
ReadFixSessionTTResultById
GetMemberStatisticsats
ShareRawHistory
ShareTranscript
DownloadTranscript
DownloadTCX
ModifyMap
MapMapToHistory
```

Из настроек скорости:

```text
Юношеский: jog 1.2, medium 3.0, high 4.6, sprint 5.5 м/с
Любительский: jog 1.5, medium 3.3, high 5.0, sprint 6.0 м/с
Профессиональный: jog 2.0, medium 4.0, high 5.5, sprint 7.0 м/с
```

Эти пороги перенесены в модуль Sportoteka Tracker Pro.


## Добавлено в этом архиве

- Калибровка поля по 4 углам.
- Перевод GPS lat/lon в field_x_m / field_y_m.
- Тепловая карта по координатам поля.
- Вкладка `Поле` в Sportoteka Tracker Pro.
