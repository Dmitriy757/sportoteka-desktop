# Live GPS Command Tester

Добавлена кнопка:

```text
Live → режим Трекер → Проверить команды GPS
```

Она по очереди отправляет все команды-кандидаты current GPS и пишет в лог:

```text
TEST TX кандидат ...
RX ...
```

Что нужно прислать разработчику:

```text
TEST TX кандидат 1: ...
RX ...
TEST TX кандидат 2: ...
RX ...
```

Если ответ `type=0x21`, это только батарея/GPS-ready.

Для настоящей live-точки нужен пакет:
- `type=0x33`;
- `type=0x43`;
- `type=0x44`;
- `type=0x45`;
- или неизвестный новый пакет, который нужно распарсить по hex.
