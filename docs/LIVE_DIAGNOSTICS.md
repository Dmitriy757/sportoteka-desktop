# Live Diagnostics

Добавлено для отладки Live от трекера:

- Live теперь показывает TX-команду current GPS прямо в логах.
- Live показывает все RX-пакеты из BLE:
  - `RX ... type=0x21` — это батарея/GPS-ready, но не координаты.
  - `RX ... type=0x33/0x43/0x44/0x45` — это GPS-пакеты, они будут сохранены.
- Добавлен heartbeat, чтобы активная сессия не становилась OFF, пока мы ждём GPS.
- В списке игроков теперь отображается `ЖДЁМ GPS`, если Live-сессия активна, но координаты ещё не пришли.

Новый API:

```text
api/tracker/heartbeat_tracker_live_session.php
```

Что проверить:

1. Вкладка Live → режим `Трекер`.
2. Переключить кандидат команды.
3. Нажать Старт Live.
4. Смотреть логи:
   - если есть только `RX ... type=0x21`, команда не отдаёт координаты;
   - нужно выбрать следующий кандидат;
   - если появится GPS-пакет, будут строки `GPS трекера: ...` и `Точка сохранена`.
