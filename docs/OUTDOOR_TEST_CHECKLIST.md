# Проверка трекера на улице

Цель: понять, где проблема — GPS трекера, сервер, калибровка поля или UI.

## Перед выходом

1. Зарядить трекер минимум до 60%.
2. Загрузить PHP и выполнить SQL из архива.
3. Проверить API с телефона:
   https://sportotekaapp.ru/api/tracker/ping_tracker.php
4. Закрыть зависшие live-сессии:
   https://sportotekaapp.ru/api/tracker/finish_active_live_sessions.php?team_id=40
5. В приложении выбрать игрока и поле.

## Быстрая проверка UI

В Live нажмите `Debug: добавить тестовую точку` 3–5 раз.
Если точка, вектор, скорость и трек появились — интерфейс работает. Тогда проблема не в дизайне и не в отрисовке, а в GPS/сервере.

## Проверка реального трекера

1. Выйти на открытое место: не в помещении, не возле высокой стены, не в машине.
2. Подключить трекер во вкладке BLE.
3. Открыть Live.
4. Выбрать режим `Трекер`.
5. Оставить `Кандидат 1: 3A`.
6. Подождать 2–5 минут, пока трекер поймает спутники.
7. Нажать `Старт Live`.
8. Пройти 20–30 метров по прямой.
9. Посмотреть Debug.

Хорошо:
```
RX 3B ... не нули
GPS: 55.xxxxxx, 37.xxxxxx
SAVE: OK
Скорость > 0
Смещение > 0
```

Плохо:
```
RX 3B 00 00 00 00 00 00 00 00
```
Это значит трекер отвечает, но текущей GPS-точки ещё нет.

Тепловая карта появится только после реальных GPS-точек, остановки Live и сохранения сессии.
