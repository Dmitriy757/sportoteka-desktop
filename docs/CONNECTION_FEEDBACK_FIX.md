# Анимация подключения трекера

Добавлено в `sportoteka_tracker_pro_screen.dart`:

- статусная карточка подключения во вкладке «Подключение»;
- анимация поиска трекера;
- анимация подключения конкретного устройства;
- понятные статусы:
  - `Идёт поиск...`
  - `Bluetooth-соединение...`
  - `Сохраняем привязку к игроку...`
  - `Успешно подключено: трекер → игрок`
- если игрок не выбран, выводится подсказка назначить владельца во вкладке «Трекеры».

Основной изменённый файл:

```text
lib/presentation/tracker/sportoteka_tracker_pro_screen.dart
```
