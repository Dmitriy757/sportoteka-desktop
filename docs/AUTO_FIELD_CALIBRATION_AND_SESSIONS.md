# Автокалибровка поля и отображение сессий игрока

## Что изменено

### 1. Поле теперь можно калибровать не вручную, а по точкам

Во вкладке `Поле` добавлены действия:

- выбрать угол `A`, `B`, `C`, `D`;
- подойти к углу поля;
- нажать `Зафиксировать телефоном`;
- или нажать `По точке трекера`, если уже получена GPS-точка от трекера.

Порядок углов:

```text
A — левый нижний
B — правый нижний
C — правый верхний
D — левый верхний
```

После сохранения это поле применяется ко всей команде и ко всем трекерам команды.

### 2. Добавлен красивый кастомный вид футбольного поля

Файл:

```text
lib/presentation/tracker/widgets/tracker_field_painter.dart
```

Теперь поле рисуется как футбольное поле: газон, полосы, штрафные, центр, маркеры A/B/C/D.

### 3. Сессия теперь привязывается к игроку корректнее

Файл:

```text
api/tracker/save_tracker_session.php
```

Если в Flutter не выбран игрок, сервер сам ищет владельца трекера:

```text
tracker_devices.device_uuid + team_id → player_id
```

То есть если трекер уже привязан во вкладке `Трекеры`, сессия будет сохранена на этого игрока.

### 4. После сохранения сессии автоматически запускается обработка

Flutter теперь после сохранения вызывает:

```text
process_tracker_session.php?session_id=ID
```

После этого сессия должна появиться во вкладке `Сессии` уже с метриками:

- дистанция;
- максимальная скорость;
- спринты;
- нагрузка;
- координаты `field_x_m`, `field_y_m`, если поле откалибровано.

## Новая зависимость

Добавить:

```bash
flutter pub add geolocator
```

Или проверить `pubspec_dependencies.yaml` в архиве.

## Android

Нужны разрешения:

```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
```

Они уже добавлены в:

```text
android_snippets/AndroidManifest_permissions.xml
```

## iOS

Добавлены строки для `Info.plist`:

```text
NSLocationWhenInUseUsageDescription
NSLocationAlwaysAndWhenInUseUsageDescription
```

## Важно про live-режим

Текущая реализация показывает сессии после выгрузки GPS-записи из трекера и сохранения на сервер. Если нужен прямой live-режим во время бега, нужно точно определить BLE-команду текущей GPS-позиции из трекера. В найденном APK такая функция есть на уровне приложения, но точный байтовый код команды ещё надо подтвердить на реальном устройстве.
