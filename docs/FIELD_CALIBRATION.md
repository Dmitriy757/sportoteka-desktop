# Определение координат по футбольному полю

GPS-трекер отдаёт широту и долготу. Чтобы получить координаты игрока именно на поле, Sportoteka использует калибровку по четырём углам.

## Углы поля

```text
D ┌───────────────┐ C
  │               │
  │               │
A └───────────────┘ B
```

- A — левый нижний угол
- B — правый нижний угол
- C — правый верхний угол
- D — левый верхний угол

Ось A → B считается длиной поля, ось A → D считается шириной.

## Что сохраняется

В таблице `tracker_gps_points` появляются поля:

```text
field_x_m — координата по длине поля в метрах
field_y_m — координата по ширине поля в метрах
is_inside_field — точка внутри поля или нет
```

## Что это даёт

После калибровки можно строить:

```text
тепловую карту на поле
траекторию движения
спринты по зонам
ускорения/торможения на карте
зоны активности
левый/правый фланг
центр
штрафную
финальную треть
```

## Формула

Точка GPS переводится в локальные метры относительно угла A. Затем вектор A→точка проецируется на оси A→B и A→D.

```text
x = projection(AP, AB)
y = projection(AP, AD)
```

Это не просто нормализация GPS-границ, а реальная координатная система футбольного поля.
