# Sportoteka 3D Pro — V17 TacticalPad Style

Эта версия усиливает Unity-редактор под стиль тренерской тактической доски TacticalPad.

## Что изменено

1. Верхняя панель переименована в `Sportoteka Tactical Board • TacticalPad Style`.
2. Добавлена плавающая панель быстрых действий:
   - 4-3-3
   - Билдап
   - Прессинг
   - Рондо
   - + кадр
   - Проиграть
   - PNG
   - Библиотека
3. Нижний док переработан как TacticalPad-палитра:
   - чистая белая закруглённая панель;
   - круглые инструменты;
   - подписи под инструментами;
   - активный инструмент выделяется зелёным.
4. Правый инспектор переименован и визуально ориентирован на контекстную панель объекта.
5. PRO-библиотека переименована в библиотеку TacticalPad: схемы, упражнения, анализ.
6. В верхнюю панель добавлена отдельная кнопка `PRO` для быстрого открытия библиотеки.

## Основной изменённый файл

`Assets/Sportoteka3DPro/Scripts/Sportoteka3DProEditorController.cs`

## Важные функции редактора

- расстановка игроков и соперников;
- мяч, пас, рывок, кривая стрелка;
- зоны анализа;
- конусы, манекены, ворота;
- текстовые подписи;
- линейка/дистанция;
- слои, скрытие, блокировка, удаление;
- сохранение кадров;
- проигрывание кадров;
- экспорт PNG;
- готовые пресеты 4-3-3, билдап, прессинг, рондо, Field Radar, брифинг клуба.

## Следующий этап

Чтобы приблизиться к полноценному TacticalPad ещё сильнее, нужно добавить:

- плавную анимацию между кадрами;
- экспорт MP4/PDF;
- библиотеку упражнений по папкам;
- импорт реального состава из Flutter/API;
- мультивыбор объектов рамкой;
- drag-and-drop игроков из состава на поле.
