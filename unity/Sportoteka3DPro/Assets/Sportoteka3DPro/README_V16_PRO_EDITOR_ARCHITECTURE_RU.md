# Sportoteka 3D Pro — V16 PRO Editor Architecture

Версия V16 перерабатывает редактор не как косметический патч, а как основу профессиональной тактической доски под будущую подписку.

## Главное изменение интерфейса

Правая часть больше не состоит из двух отдельных «плавающих карточек». Теперь это единый PRO-инспектор:

- вкладка **Свойства** — контекстная информация по выбранному объекту;
- вкладка **Слои** — список всех объектов на поле с выбором, скрытием, блокировкой, копированием и удалением;
- вкладка **Стиль** — цвет, толщина, прозрачность, тип линии/пунктира/стрелки;
- вкладка **Анимация** — кадры, запуск, пример, очистка кадров.

## Исправления UX

- Вместо технических названий `mini_goal`, `pass`, `hatched_zone` показываются нормальные названия: Мини-ворота, Пас, Зона анализа и т.д.
- Инспектор теперь контекстный: для мини-ворот не показываются лишние «линия/пунктир/стрелка» в свойствах.
- Слои стали частью единого правого инспектора и не накладываются отдельной карточкой снизу.
- Добавлены `visible` и `locked` в `Sportoteka3DProPlanItem`.
- Скрытые слои не отрисовываются на поле, но остаются в менеджере слоёв.
- Выбор объекта обновляет цвет/толщину/прозрачность в инспекторе.

## Новый функционал под PRO

Добавлена PRO-библиотека шаблонов:

- Схема 4-3-3
- Билдап от ворот
- Контратака 3v2
- Высокий прессинг
- Рондо 5v2
- Скоростные станции
- Field Radar
- Брифинг клуба

## Новые пресеты

В `Sportoteka3DProPresets.cs` добавлены:

- `CounterAttack3v2Pack()`
- `Rondo5v2Pack()`
- `SpeedStationsPack()`

## Иконки

Все `tg_*.png` в `Resources/Icons` перерисованы в едином стиле: прозрачный фон, жирная белая маска, чтобы Unity мог нормально перекрашивать их внутри круглых кнопок.

## Проверка в Unity

Unity Editor в среде сборки недоступен, поэтому после импорта необходимо проверить:

1. Открытие сцены `SportotekaFootballBoard.unity`.
2. Правый PRO-инспектор: вкладки Свойства / Слои / Стиль / Анимация.
3. Выбор объектов с поля и через вкладку Слои.
4. Скрытие/блокировка/копирование/удаление слоёв.
5. PRO-библиотеку и загрузку новых пресетов.
6. Экспорт PNG/JSON.
