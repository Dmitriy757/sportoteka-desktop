# Sportoteka 3D Pro — V15 Layers / Selection / Clear Icons

Что исправлено в этой версии:

1. Поле теперь открывается чистым, без автоматического нагромождения демо-пресетов.
   Пресеты TacticalPad/PRO остаются в верхнем баннере и добавляются только по нажатию.

2. В нижний круглый док добавлена отдельная кнопка `Выбор`.
   Теперь после добавления объектов можно явно перейти в режим выделения и выбирать элементы на поле.

3. Справа добавлена панель `Слои на поле`.
   Каждый добавленный объект отображается отдельной строкой: игрок, пас, рывок, зона, текст, ворота и т.д.
   По нажатию на строку объект выделяется на поле. Есть быстрые действия: копия, удалить, поверх, очистить.

4. Улучшено выделение объектов на поле.
   Добавлены невидимые selection-proxy коллайдеры, поэтому легче попадать по стрелкам, игрокам, зонам и тексту.
   Raycast теперь перебирает все попадания и отдаёт приоритет игрокам/мячу/точечным объектам, а не большим зонам.

5. Перерисованы иконки `tg_*.png`.
   Иконки стали крупнее, жирнее и сделаны как белые прозрачные маски, чтобы нормально краситься:
   активный зелёный круг — белая иконка, неактивный белый круг — тёмная иконка.

6. Исправлены горячие клавиши Undo/Redo для нового Input System: Z/Y теперь тоже обрабатываются.

Основной изменённый файл:
`Sportoteka3DPro/Scripts/Sportoteka3DProEditorController.cs`

Иконки:
`Sportoteka3DPro/Resources/Icons/tg_*.png`
