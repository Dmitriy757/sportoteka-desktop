# Sportoteka 3D Pro — V13 Dock Icons Fix

Исправление нижнего меню по замечанию: «нужны только круги, внутри не видны иконки».

## Что изменено

- Нижний док больше не имеет общей подложки/панели.
- Внизу остаются только отдельные круглые кнопки-инструменты.
- Подписи под нижними кнопками убраны, чтобы меню не выглядело тяжёлым.
- Мобильный док тоже переведён на отдельные floating-orbs без заднего меню.
- Все `tg_*.png` иконки очищены от старых белых квадратных подложек.
- Иконки переведены в прозрачные alpha-mask ассеты, поэтому теперь корректно окрашиваются кодом:
  - активная зелёная кнопка → белая иконка;
  - неактивная белая кнопка → тёмная иконка.
- Для UI-иконок отключён `raycastTarget`, чтобы клики проходили в круглую кнопку, а не в дочернюю картинку.

## Основной файл

`Sportoteka3DPro/Scripts/Sportoteka3DProEditorController.cs`

- `BuildPremiumBottomDock`
- `BuildPremiumMobileDock`
- `PremiumDockTool`
- `AddIcon`
