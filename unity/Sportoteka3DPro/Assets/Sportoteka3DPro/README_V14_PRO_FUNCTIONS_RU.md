# Sportoteka 3D Pro V14 — PRO Tactical / Analysis Workspace

Версия V14 перерабатывает не только внешний вид, но и функциональный слой редактора под профессиональную тактическую доску уровня TacticalPad / Once Sport Coach Board / Metrica-style Field Radar.

## Что добавлено

### 1. Рабочие баннеры режимов
Под верхней панелью появился открывающийся PRO-баннер. Он меняется в зависимости от выбранного режима:

- **Схема**: 4-3-3, билдап, контратака, стандарт, состав, библиотека инструментов.
- **Анализ**: прессинг, Field Radar, линия обороны/офсайд, полный анализ, дистанции, зоны давления.
- **Упражнение**: готовое упражнение, рондо 5v2, скоростные станции, конусы, манекены, инвентарь.
- **Анимация**: сохранить кадр, проиграть кадры, пример анимации, очистка кадров, JSON.
- **Калибровка**: 4 точки поля 105×68, линейка, 2D поле, калибровочная точка, Field Radar.
- **Брифинг**: Showcase, логотип команды, экспорт PNG/JSON, текст, модель подписки.

### 2. Новые футбольные пресеты
Добавлены рабочие пресеты:

- Контратака 3v2
- Компактность блока
- Линия обороны / офсайд
- Рондо 5v2
- Скоростные станции
- Полный пакет анализа: прессинг + Field Radar + компактность

### 3. Библиотека инструментов PRO
Добавлено модальное окно со всеми инструментами:

- Игрок, соперник, мяч
- Пас, рывок, кривая, линия, пунктир
- Зона, фокус, офсайд, метры
- Конус, манекен, мини-ворота, большие ворота
- Круг, лестница, барьер, гейт, стойка
- Текст, логотип команды, точка калибровки

### 4. Основа под подписку
В интерфейс добавлен отдельный модальный блок тарифов:

- FREE — базовая доска
- PRO — анализ, анимация, Field Radar, JSON
- CLUB — клубная лицензия, составы, API, брендированные шаблоны

Это пока UX-структура, но она подготовлена для передачи тарифа из Flutter/API и последующего скрытия/открытия функций.

### 5. Исправления рабочего поведения

- Undo/Redo теперь доступны и через кнопки, и через клавиши Z/Y.
- Нижний док остаётся кругами без задней панели.
- Статус действий теперь виден отдельным компактным баннером.
- Переключение режимов обновляет активный баннер и список доступных функций.
