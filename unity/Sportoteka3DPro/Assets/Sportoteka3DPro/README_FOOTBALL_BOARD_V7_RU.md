# Sportoteka 3D Pro — Football Board V7

Пакет переделан под футбольный тактический редактор. Все универсальные спортивные режимы убраны: интерфейс, пресеты и быстрые действия теперь ориентированы только на футбол.

## Что изменено

- Новый интерфейс: `Sportoteka Football Board` с чистой верхней панелью, левой футбольной навигацией, нижним доком инструментов и правыми панелями стиля/инспектора.
- Режимы только для футбола:
  - `Схема` — расстановки, игроки, соперник, пасы, рывки, зоны.
  - `Анализ` — прессинг, офсайд, связи игроков, измерение дистанций, зоны давления, Field Radar.
  - `Упражнение` — конусы, мячи, манекены, лестницы, барьеры, гейты и ворота.
  - `Анимация` — кадры, проигрывание последовательности и пример 4-3-3.
  - `Калибровка` — точки футбольного поля 105×68 и измерения в метрах.
  - `Брифинг` — клубный стиль, подписи и презентационный слой.
- Новые футбольные пресеты:
  - 4-3-3;
  - билдап через 6-го;
  - угловой стандарт;
  - триггер прессинга;
  - Field Radar / компактность;
  - упражнение пас → открывание → завершение;
  - калибровка поля;
  - showcase/брифинг.
- Экспорт из Unity:
  - PNG через кнопку `PNG`;
  - JSON через кнопку `JSON`;
  - сохранение/загрузка локального плана.
- Flutter-интеграция:
  - добавлен объект совместимости `FlutterBridge`;
  - поддержаны вызовы `LoadScheme`, `SetCameraPreset`, `ClearScheme`, `ResetScene`, `ExportScheme`.

## Главные файлы

- `Scripts/Sportoteka3DProEditorController.cs` — основной UI и логика футбольной доски.
- `Scripts/Sportoteka3DProPresets.cs` — футбольные пресеты.
- `Scripts/Sportoteka3DProPlanItem.cs` — режимы и инструменты, только футбольные режимы.
- `Scripts/Sportoteka3DProBridge.cs` — demo-сцена с футбольными объектами.
- `Scripts/Sportoteka3DProFlutterBridgeProxy.cs` — прокси для Flutter.
- `Scripts/Sportoteka3DProRuntimeBootstrap.cs` — автосоздание Bridge и FlutterBridge.
- `Editor/Sportoteka3DProSetupEditor.cs` — создание сцены `SportotekaFootballBoard`.

## Как открыть в Unity

1. Скопируй папку `Sportoteka3DPro` в `Assets/` Unity-проекта.
2. В Unity выбери меню: `Sportoteka 3D Pro → Open Football Board Scene`.
3. Нажми Play.
4. Проверь режимы слева: `Схема`, `Анализ`, `Упр.`, `Аним.`, `Калибр.`, `Брифинг`.

## Важно

Unity Editor в среде сборки ChatGPT недоступен, поэтому изменения проверены статически по структуре C# файлов, ссылкам на режимы и отсутствию универсальных спортивных режимов. Финальную компиляцию нужно проверить в твоём Unity Editor.
