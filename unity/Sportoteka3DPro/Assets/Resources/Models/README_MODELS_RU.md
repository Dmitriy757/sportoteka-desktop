# Модели для Sportoteka 3D Pro

Папка для бесплатных моделей.

Поддерживаемые имена:
- `player_home`
- `player_away`
- `ball`
- `cone`
- `goal`

Unity должен видеть их как prefab или импортированный GameObject в `Resources/Models`.

Рекомендуемые бесплатные источники:
- Kenney — CC0 assets
- Quaternius — CC0 3D characters / animations
- Poly Haven — CC0 models/HDRI/textures
- ambientCG — CC0 PBR textures
