# Текстуры для Sportoteka 3D Pro

Базовое поле создаётся процедурно, поэтому внешняя текстура не обязательна.

Если хочешь заменить траву на PBR:
1. Скачай grass/albedo/normal/roughness с ambientCG или Poly Haven.
2. Положи файлы сюда.
3. Позже можно подключить их в `Sportoteka3DProMaterialFactory.Grass`.
