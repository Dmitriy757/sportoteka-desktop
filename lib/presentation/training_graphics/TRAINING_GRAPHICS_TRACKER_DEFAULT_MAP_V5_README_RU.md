# Training Graphics v5 — карта по умолчанию как в Tracker

Изменения:
- новый документ открывается сразу в `3D PRO`;
- стартовый наклон камеры приведён к Tracker (`-0.34`);
- стартовая перспектива синхронизирована с Tracker (`0.00135`);
- первый fit теперь учитывает активный режим 3D, а не принудительно открывает 2D;
- базовое поле больше не зависит визуально от старой картинки `assets/training/field.png`;
- стандартная карта поля рисуется в стиле Tracker: зелёный градиент, полосы газона, белая разметка, центр, штрафные и воротные;
- фон вокруг поля в 3D соответствует Tracker: светлый градиент + тёмная подложка/тень;
- пользовательская текстура поля по-прежнему накладывается поверх стандартной карты;
- сохранённые схемы с явным `is_3d_mode` сохраняют свой режим; старые документы без этого поля получают новый Tracker-default.
