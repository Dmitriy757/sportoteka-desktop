# Training Graphics V7 — карта один в один с актуальным Tracker

База: V6 с отдельным окном «Анимация».

## Что исправлено

Training Graphics больше не использует старую тёмно-зелёную стилизацию поля.
Основное поле синхронизировано с актуальным полем Tracker, которое используется
в Live и полном разборе матча (`_RuntimeFieldPainter` / `_ActionPitchPainter`).

### Поле
- базовый цвет: `#76947B`;
- полосы газона: `#719078` / `#819E86`;
- разметка: белая с opacity `0.78`, stroke `1.5`;
- радиусы, внутренний inset, центр, штрафные, вратарские и точки пенальти —
  в тех же пропорциях, что в Tracker;
- фон 3D: `#DDE7E1 -> #F6F8F7`;
- нижняя 3D-подложка: `#284B38`;
- мини-карта переведена на ту же палитру.

### 3D камера
- настоящая perspective: `0.00135`;
- стартовый tilt: `-0.34`;
- стартовый zoom: `0.96`;
- zoom range: `0.96 .. 1.38`;
- +/-: шаг `0.08`;
- orbit horizontal: `0.48 deg/px`;
- tilt vertical: `0.0065 rad/px`;
- reset возвращает Tracker-default;
- круглые кнопки/джойстик приведены к размерам и цветам Tracker.

### Рисование в 3D
Включена настоящая перспективная матрица. Для точного попадания линий,
квадратов, объектов и выбора объектов используется обратное преобразование
гомографии плоскости поля. Поэтому координаты редактора остаются корректными
при наклоне/повороте камеры.

### Своя текстура
Пользовательская текстура сохранена. Она является дополнительным слоем поверх
стандартных полос Tracker, а футбольная разметка остаётся сверху.
Если своей текстуры нет, поле визуально использует штатный Tracker-дизайн.
