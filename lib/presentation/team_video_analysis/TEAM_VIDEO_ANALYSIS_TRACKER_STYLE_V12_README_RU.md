# Team Video Analysis — Tracker / CMR parity v12

Изменения выполнены по актуальному `tracker 14(4)`.

## Общий каркас
- Встроенный в Club Workspace режим использует постоянный левый rail 52 px, как Tracker.
- Rail: белый фон, 4 px боковые отступы, 6 px сверху/снизу, кнопки 38x38, радиус 10, фирменная зелёная кнопка модуля 40x40.
- Рабочая область начинается сразу после rail: без внешней рамки, декоративного gutter и карточки вокруг всего модуля.
- Список матчей уменьшен с 420 px до 292 px (330 px только на очень широком окне).
- Между rail / списком / рабочей зоной оставлены только тонкие структурные разделители `#E9ECEA`.

## Полный TeamVideoAnalysisScreen
- Убран псевдо-macOS chrome с красной/жёлтой/зелёной точками.
- Шапка сделана в геометрии Tracker: 54–56 px, лёгкий заголовок и подпись, компактные действия справа.
- Полноразмерное боковое меню выполнено по Tracker CMR-паттерну: активная зелёная вертикальная метка, радиус 9, иконка 17 px, лёгкий текст и фирменная точка.
- Убраны двойные разделительные линии между шапкой, sidebar и контентом.
- Цвета синхронизированы: `#00A750`, `#067A46`, `#F3FAF6`, `#F7F8F7`, `#E9ECEA`, `#0B0F14`, `#5F6670`.

## Список матчей
- Строки стали плотными, как списки Tracker/CMR.
- Убраны карточные обводки.
- Активный матч = мягкий зелёный фон + фирменная светящаяся точка.
- Размеры и веса текста уменьшены; на экране помещается больше матчей.

## Правая рабочая зона
- Убрана внешняя карточка вокруг деталей и видеоразбора.
- Информационные и служебные блоки используют фоновые баннеры вместо рамок.
- Уменьшены радиусы и тяжёлые веса шрифта.
- Видеоразбор открывается в той же бесшовной рабочей области.

## Типографика
- Добавлен `AppTypography`.
- Единый шрифт применяется к CmrVideoAnalysisPanel, TeamVideoAnalysisScreen и VideoMatchReviewScreen.
- CMR AI и таблицы ТТД больше не фиксированы на Segoe UI / Roboto.

Основной изменённый файл: `team_video_analysis/team_video_analysis_unified.dart`.
Остальные файлы в модуле остаются compatibility bridges и продолжают экспортировать unified-файл.
