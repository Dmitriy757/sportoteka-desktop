# Отдельный раздел «Готовность» в профиле игрока

«Готовность» вынесена из карточки игрока в самостоятельную вкладку:

- итоговый статус и балл из 100;
- нагрузка за 7 дней и отношение 7/28;
- сон, боль и RPE из дневной анкеты;
- пояснение, когда расчёт выполнен только по GPS;
- рекомендации тренеру;
- переход из нижней строки в полный раздел Tracker → «Готовность».

Профиль получает анкету из `api/tracker/get_tracker_readiness.php` и считает
нагрузку по тем же правилам, что и Tracker. Серверный пакет и миграция находятся
в актуальном архиве Tracker.
