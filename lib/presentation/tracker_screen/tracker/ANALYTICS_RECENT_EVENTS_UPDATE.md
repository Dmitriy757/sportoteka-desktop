# Analytics recent events update

- Клик по игроку в «Рейтингах дня» открывает нижнюю карточку последнего события в стиле Live.
- Карточка показывает дистанцию, скорость, спринты, HIR/VHIR, ускорения/торможения и нагрузку.
- Кнопка «Подробнее в аналитике» выбирает игрока и открывает вкладку «Команда».
- Правые баннеры раздела «Пульс» уменьшены по высоте, чтобы помещаться без обрезания.
- GPS-точки на карте активности уменьшены; подписи выводятся реже, маршрут стал чище.
