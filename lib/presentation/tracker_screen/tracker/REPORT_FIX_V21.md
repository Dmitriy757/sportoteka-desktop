# Report fixes V21

- The report player picker now displays only players attached to the selected session.
- Default export player IDs are limited to attached session participants.
- Session rows use the training/session title instead of the player name and show participant count.
- Report preview route markers were reduced to analytics-like sizes.
- Report preview heatmap radius and opacity were reduced.
- PDF/HTML route markers and heatmap spots were reduced.
- Technical GPS point counts were removed from user-facing report descriptions.
