# Honor / MagicOS BLE fix

Изменено:
- найденные GPS-трекеры и Polar больше не очищаются перед повторным поиском;
- добавлена пауза 650 мс между `stopScan()` и `startScan()`;
- минимальный поиск увеличен до 12 секунд, расширенный — до 15 секунд;
- GPS scan стабильно использует Android location mode, так как приложение уже запрашивает `locationWhenInUse`;
- в Android manifest snippet добавлен обязательный BLE feature.

На Honor перед тестом:
1. Настройки → Приложения → SPORTOTEKA → Батарея → Без ограничений.
2. Разрешения → Устройства поблизости и Местоположение → Разрешить при использовании.
3. Включить системную Геолокацию, Bluetooth и экран планшета.
4. Отключить подключение Polar/трекеров на других телефонах рядом.
5. После установки новой APK один раз перезагрузить планшет.

Важно: перенесите строки из `android_native/AndroidManifest_permissions_snippet.xml` в настоящий `android/app/src/main/AndroidManifest.xml`, если их там ещё нет.
