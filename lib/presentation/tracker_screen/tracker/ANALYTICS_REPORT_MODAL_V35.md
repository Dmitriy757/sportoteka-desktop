# Analytics report modal v35

- Кнопка «Отчёты» больше не переключает аналитику на отдельную вкладку.
- При наличии выбранной одиночной сессии она сразу открывает большое окно «Выбор отчёта».
- Окно использует игроков, выбранных в аналитике.
- После закрытия окна пользователь остаётся на прежней вкладке аналитики.
- Если сессия не выбрана, открывается «Выбор аналитики».
- Сохранены живой предпросмотр, выбор блоков, PDF и Excel.
