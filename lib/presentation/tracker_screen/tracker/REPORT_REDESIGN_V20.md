# Report redesign V20

- Тепловая карта отчёта: уменьшен радиус и прозрачность пятен, чтобы она совпадала по восприятию с аналитикой.
- Маршрут: уменьшены GPS-маркеры и ореолы.
- Экспорт: убраны технические счётчики GPS/HR-точек из шапки и KPI.
- Выбор игроков: список ограничен участниками выбранной сессии (движение, GPS, HR или нагрузка), с безопасным fallback.
- Логотип команды остаётся в шапке HTML/PDF и на экране отчёта.
- Карточки и таблицы облегчены: меньше рамок, фоновые акценты и подчёркивание зелёным.
- Подпись heatmap теперь объясняет плотность без количества точек.
