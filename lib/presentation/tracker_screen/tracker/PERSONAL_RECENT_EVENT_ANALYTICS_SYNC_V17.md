# Personal Recent Event Analytics Sync v17

- Последнее событие сначала загружает полную завершённую сессию через `player_get_sessions.php`.
- GPS-точки загружаются тем же endpoint, который используется аналитикой: `player_get_session_points.php`.
- Метрики бега, ходьбы и спринтов берутся из серверной аналитики; при отсутствии готовых полей безопасно восстанавливаются из скорости и расстояния GPS-точек.
- Карточки и типографика облегчены в стиле аналитики.
- Live и последнее событие используют одинаковые поля данных без выдуманных значений.
