# Tracker — seamless roster-style redesign

Основа интерфейса: `cmr_club_roster_panel.dart`.

## Правила
- Рабочие экраны используют единое белое полотно.
- Внешние карточки и окна без скруглений и теней.
- Колонки и секции разделяются линиями `#E9ECEA`.
- Скругления остаются только у кнопок, чипов, статусов, pop-up и modal sheet.
- Фирменный зелёный `#00A750` используется для активной вкладки, выбранного игрока и главного действия.
- KPI: число + подпись, без декоративной иконки-карточки.
- GPS/Polar: цветная точка + текст.
- Мобильные секции идут на всю ширину без серых зазоров между «окнами».

## Обновлённые области
Live, Workspace, Analytics, Reports, Player Activity, Personal Trainings, Calendar, Notifications, Pro Analytics.
