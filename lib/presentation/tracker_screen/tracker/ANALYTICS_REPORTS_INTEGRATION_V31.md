# Аналитика → Отчёты v31

- В конец верхних вкладок аналитики добавлена вкладка «Отчёты».
- Отчёт использует текущую выбранную в аналитике сессию.
- Повторный календарь внутри отчётов не требуется.
- Выбранные в аналитике игроки автоматически передаются в список выгрузки отчёта.
- Если сессия ещё не выбрана, вкладка показывает кнопку «Открыть выбор аналитики».
- В отчёте остаются галочки игроков, секций, PDF и Excel/CSV.
