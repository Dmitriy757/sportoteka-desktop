# Аналитика пульса — режимы и ИИ-нагрузка

## Как определяется режим тренировки
Polar H10 измеряет только пульс и интервалы RR. Он не определяет автоматически, что игрок выполняет бег, работу в зале, силовую тренировку или работу на поле.

Режим выбирается пользователем при старте личной тренировки и сохраняется в сессии:
- `run` — Бег
- `gym` — Зал
- `strength` — Сила
- `field` — Поле

Для фильтра режима в аналитике сервер должен добавлять к точкам Polar одно из полей:
`activity_type`, `training_type`, `mode` или `activity`.

Пример:
```json
{
  "player_id": 79,
  "bpm": 168,
  "measured_at": "2026-07-11 15:31:20",
  "activity_type": "field"
}
```

## Что добавлено
- Заголовок справа теперь только `Polar H10`.
- Фильтр режимов: Все режимы / Бег / Зал / Сила / Поле.
- Отдельная правая панель `Точки нагрузки · ИИ`.
- Явные красные события Z4–Z5 по каждому игроку.
- Нажатие на событие автоматически увеличивает график и переводит к выбранному времени.
- Нажатие прямо на график выбирает ближайшую HR-точку.
- Для выбранной точки показываются игрок, время, bpm, зона и режим.
- Добавлена локальная тренерская ИИ-интерпретация нагрузки.

Важно: автоматические выводы являются подсказкой тренеру, а не медицинским заключением. Для возрастной персонализации серверу желательно передавать дату рождения или возраст игрока и индивидуальный HRmax.
