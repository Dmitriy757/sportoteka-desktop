# Sportoteka Performance Report v120

Обновление раздела «Отчёты» выполнено единым пакетом.

## Flutter
- Добавлена Sportoteka Performance Matrix в основной экран отчёта.
- Таблица объединяет общую информацию, механику, локомоторику и Polar.
- Добавлены прозрачные производные показатели «Интенсивность», «Баланс» и «Статус».
- Цветовая индикация: оптимально / повышено / высоко / нет данных.
- В экспорт передаётся секция `performance_matrix`.

## Сервер
- Расширен расчёт отчёта: `ai_load`, `intensity_score`, `load_vs_team_percent`, `load_balance_percent`, `load_status`.
- PDF получил широкую Performance Matrix с GPS, механикой, V3/V4/V5, HR и статусом нагрузки.
- CSV/Excel-совместимый экспорт получил новые колонки.

## Важно
Статус нагрузки является тренерским индикатором отклонения от командной нагрузки, а не медицинским диагнозом и не прогнозом травмы.
