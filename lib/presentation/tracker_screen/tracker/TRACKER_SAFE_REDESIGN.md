# Tracker safe redesign

Эта версия сохраняет существующую архитектуру и локальные палитры трекера.

- Не добавляет STColors, STText, STDecor или новые UI-зависимости.
- Не меняет BLE, GPS, Polar, API и модели данных.
- Дизайн реализован внутри существующих файлов и классов (_TD, _AA, _OF и др.).
- Белая рабочая поверхность, минимальные рамки, компактные отступы и фирменный зелёный сохранены.
