# Пульс — расширение аналитики

## Как задаётся режим
Polar H10 измеряет только ЧСС и RR-интервалы. Режим тренировки выбирает игрок до старта: Поле, Бег, Зал, Сила или Только Polar.

Flutter передаёт `activity_type`:
- при старте личной Live-сессии;
- в heartbeat snapshot;
- с GPS-точками;
- с каждой точкой Polar.

Сервер должен сохранять `activity_type` в live-сессии, итоговой сессии и HR-записи либо получать его через связь с `live_session_id`.

## Новое в аналитике
- мини-карта всей тренировки под масштабом графика;
- красные столбцы — интервалы Z4–Z5;
- зелёная рамка — текущий увеличенный участок;
- красный маркер — выбранная точка нагрузки;
- точное время и минута от начала сессии;
- увеличенная метка выбранной точки на основном графике;
- понятные карточки «Средний / Максимум / Разница» вместо узкого графика;
- фильтр по режимам тренировки;
- ИИ-комментарии к точкам высокой нагрузки.

## Серверный контракт HR-точки
```json
{
  "player_id": 79,
  "live_session_id": 206,
  "bpm": 168,
  "measured_at": "2026-07-11T15:31:20+03:00",
  "activity_type": "strength"
}
```
