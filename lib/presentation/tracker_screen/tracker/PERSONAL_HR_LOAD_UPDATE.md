# Пульс и нагрузка личных тренировок

Добавлено в интерфейсе:
- масштаб графика ЧСС от 1x до 8x;
- ползунок положения выбранного временного окна;
- красная область Z4–Z5 от 160 bpm;
- процент точек высокой нагрузки;
- явный вид личной тренировки в Live-карточке;
- предупреждение «НАГРУЗКА» в Live при HR >= 160 или Load >= 80.

Для точного отображения вида тренировки API должен отдавать `activity_type` или `activity_label` со значениями `run`, `gym`, `strength`, `field`.
