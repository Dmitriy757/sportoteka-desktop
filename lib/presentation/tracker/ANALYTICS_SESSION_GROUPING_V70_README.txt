SPORTOTEKA TRACKER — ANALYTICS SESSION GROUPING V70

Что исправлено

1. Командная тренировка больше не распадается в календаре на отдельные
   карточки по каждому игроку.
2. Все серверные session_id одной командной тренировки объединяются в одну
   карточку:
   - количество игроков;
   - имена участников;
   - количество внутренних записей;
   - суммарная дистанция и спринты;
   - максимальная скорость;
   - наличие GPS и Polar H10.
3. При выборе командной тренировки аналитика сохраняет весь набор session_id,
   а не только запись одного игрока.
4. Вкладка «Пульс» работает по текущей области:
   - выбрана тренировка — только участники этой тренировки;
   - выбран «Весь день» — все тренировки выбранной даты;
   - чипы «Все / игрок» дополнительно фильтруют игроков внутри области.
5. В «Пульсе» сверху добавлена явная подпись текущей области, чтобы было видно,
   показывается одна тренировка или весь день.
6. Если основной endpoint пульса пуст, fallback отчёта объединяет данные Polar
   всех записей выбранной командной тренировки, а не только первой записи.
7. Счётчики на календаре и в сводке показывают количество тренировок.
   Количество технических записей игроков показывается отдельно.

Как формируется группа

- Сначала используется серверный идентификатор командной тренировки, если он
  присутствует в ответе API.
- Для старого API без group id командные записи безопасно объединяются только
  в пределах одного дня и при близком времени старта/завершения.
- Личные тренировки никогда не объединяются между собой.

После замены файлов выполните полный Hot Restart.
