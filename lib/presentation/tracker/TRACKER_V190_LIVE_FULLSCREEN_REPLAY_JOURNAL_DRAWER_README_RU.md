# Tracker V190 — полноэкранный Live + выезжающий Replay-журнал

## Live
- В левом CMR-меню Live добавлена команда «На весь экран» / «Свернуть Live».
- При разворачивании внешняя rail-навигация Tracker схлопывается, но сам LivePanel остаётся в том же месте дерева и не теряет текущую BLE/GPS/Polar-сессию.
- В полноэкранном Live сверху появляется двухрядная лента игроков как в полном разборе аналитики.
- Карточки игроков показывают online-состояние, GPS, дистанцию, текущую/максимальную скорость, HR, спринты и нагрузку.
- Слева остаётся быстрый список игроков и переключатели Поле / Игроки / Все карточки / Журнал / Разбор Live / Настройка.
- «Все карточки» больше не закрывает левое меню — можно мгновенно переключаться между режимами.
- Шрифт остаётся единым CMR/AppTypography.

## Имена игроков
- Добавлено отдельное displayName: серверное `name` не меняется, поэтому сопоставление старых сессий не ломается.
- Для UI legacy-имя «Имя Фамилия» отображается как «Фамилия И.» / «Фамилия Имя» в нужных местах.
- Исправлено отображение в верхних карточках Live/Replay, roster и строках Replay-журнала.

## Повтор матча / журнал
- На desktop Журнал больше не зажимается в нижней части правой колонки.
- Нажатие «Журнал» открывает отдельное выезжающее окно справа.
- Окно имеет собственную большую высоту и независимый вертикальный список событий.
- Нажатие на событие по-прежнему переводит курсор матча к нужному моменту.
- «Игроки» закрывает окно журнала; Pit Wall также закрывает журнал, чтобы режимы не накладывались.
- В левое меню полного разбора добавлена быстрая команда «Журнал».
