SPORTOTEKA Tracker V110 — Session Preview Height

Основа: tracker 18 / V109.

Изменения:
- при выборе подробной сессии правая панель больше не оставляет сверху большой блок «Тренировки дня» и KPI дня;
- в режиме подробностей остаётся компактная верхняя строка «Подробности сессии» с кнопкой назад;
- кнопка «Назад к списку сессий» больше не занимает отдельный высокий баннер внутри контента;
- подробности выбранной сессии начинаются выше и получают больше вертикального места;
- список сессий и KPI дня возвращаются после нажатия стрелки назад.
