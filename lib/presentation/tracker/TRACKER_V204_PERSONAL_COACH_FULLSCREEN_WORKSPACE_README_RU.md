# V204 — Личные тренировки / Тренерский контроль: fullscreen workspace

Изменены:
- `screens/tracker_match_workspace_screen.dart`
- `widgets/player_training_notifications_panel.dart`

Что сделано:

1. Раздел «Личные тренировки» в embedded Club Workspace теперь открывается сразу в root fullscreen Overlay — по тому же принципу, что Live и полный экран «Карта». Внешний CMR rail и нижний Dock Sportoteka не уменьшают рабочую область.
2. На desktop добавлена собственная левая навигация тренерского центра: Сессии / Live / События / Сравнение / Календарь.
3. Стартовый экран — именно выбор сессии. Показывается архив завершённых личных тренировок, текущий Live, фильтр игроков, предупреждения и полнота данных.
4. Кнопка «Открыть» больше не создаёт ещё одну модалку. Сессия открывается внутри того же fullscreen workspace.
5. Подробный экран выбранной тренировки использует большую компоновку 70/30: слева все данные сессии (GPS, Polar, скорость, нагрузка, графики и другие уже существующие метрики), справа — внимание тренера, полнота данных, события и журнал.
6. Стрелка «назад» в подробной сессии возвращает к выбору сессии, не закрывая весь тренерский центр.
7. Текущий личный Live в открытом подробном экране продолжает получать обновлённые данные из общего polling состояния.
8. Кнопка «К Tracker» внизу собственной левой панели закрывает fullscreen и возвращает в обычный Tracker.
9. Переход из личной сессии в Аналитику снимает fullscreen Overlay только после разрешения выбранной сессии, чтобы не было белого промежуточного экрана.
10. Удаление overlay отложено относительно pointer/mouse callback, чтобы не возвращать macOS/Web `MouseTracker.updateAllDevices` assertion.

Архив V204 собран поверх V203 FIELD SYNC, поэтому синхронизация геометрии поля Live ↔ карта разбора сохранена.
