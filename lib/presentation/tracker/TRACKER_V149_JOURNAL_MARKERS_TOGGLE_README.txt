TRACKER V149 — JOURNAL MARKERS TOGGLE
=====================================

База: V148 3D Camera Build Fix.

Изменения:
1. Точки Live Replay Journal на карте по умолчанию ВЫКЛЮЧЕНЫ.
2. Верхняя кнопка слоя переименована в «Журнал» и включает/выключает journal markers.
3. В меню «Точки» добавлен отдельный переключатель «Точки журнала».
4. Верхняя кнопка «Журнал» и переключатель в меню «Точки» используют один state,
   поэтому всегда синхронизированы.
5. Фильтры «Все точки / Ходьба / Бег / HIR / Спринт / Ускорения / Торможения /
   Повороты / Остановки» остались независимыми от journal markers.
6. Клики по Replay-маркерам в режиме «Матч» продолжают работать, когда слой включён.

PHP / БД: изменений не требуется.
