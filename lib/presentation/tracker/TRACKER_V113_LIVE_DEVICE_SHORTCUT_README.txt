SPORTOTEKA Tracker V113 — Live device shortcut

- В таблице «Игроки / live-данные» рядом с GPS/Polar добавлена отдельная кнопка устройств.
- Если игроку не хватает GPS или Polar, кнопка подсвечивается мягким зелёным и показывает add-link.
- Нажатие открывает раздел «Устройства» с уже выбранным этим игроком.
- Вкладка автоматически выбирается по отсутствующему датчику: сначала GPS, затем Polar.
- Если оба датчика назначены, открывается GPS для просмотра/замены.
- BLE автоматически не перезапускается: существующие подключения не трогаются.
