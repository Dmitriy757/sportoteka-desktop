SPORTOTEKA TRACKER — TABLET/DESKTOP CONCEPT V98
2026-08-12

V98 продолжает мобильную V94/V97 основу и исправляет desktop/tablet UX по согласованному белому концепту.

КЛЮЧЕВЫЕ ИЗМЕНЕНИЯ
1. ПК и планшет: единая постоянная светлая vertical rail навигация с иконками слева.
   - Убрано tablet bottom menu.
   - Нет тёмной/чёрной rail панели.
2. LIVE ПК/планшет:
   - верхняя строка управления Live;
   - большое поле/тепловая карта слева;
   - отдельная панель «Игроки онлайн» справа (или снизу на узком portrait tablet);
   - реальные аватарки игроков;
   - скорость, ЧСС, нагрузка в строках игроков;
   - нижняя KPI-полоса: дистанция, средняя/макс. скорость, спринты, ЧСС, нагрузка.
3. Устройства ПК/планшет:
   - основной режим «Подключение»;
   - список игроков слева;
   - найденные GPS/Polar занимают всю основную рабочую область;
   - отдельный режим «Назначенные» с таблицей сохранённых устройств;
   - явные кнопки «Подключить GPS» / «Подключить Polar»;
   - пошаговая подсказка подключения;
   - планшетная таблица без обязательного горизонтального скролла.
4. Игроки:
   - исправлена огромная высота карточек;
   - фиксированная компактная сетка, реальные фотографии, номер/позиция/GPS/Polar/online.
5. Обзор:
   - полноценная «Быстрая панель действий» 4x2 как в согласованном desktop concept:
     Начать LIVE / Добавить игрока / Назначить трекер / Импорт сессии /
     Экспорт данных / Создать отчёт / Проверка GPS / Синхр. Polar.

СЕРВЕРНАЯ ЛОГИКА
BLE/GPS/Polar, Live API, серверные сессии и PHP API не заменены фейковыми реализациями.
Новые UI-экраны используют существующие сервисы, потоки найденных Bluetooth устройств и реальные avatar URL игроков.

ЗАМЕНА
Архив содержит корневую папку tracker/. Сделайте backup старой tracker/ и замените её целиком.
