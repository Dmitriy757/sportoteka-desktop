SPORTOTEKA TRACKER V117 — ВСЕ КАРТОЧКИ + ЛЕНТА МОМЕНТОВ

Изменено только Flutter UI (PHP V116 LIVE EVENTS остаётся тем же).

1. Кнопка «Все карточки» снова открывает старое полноразмерное окно с сеткой карточек игроков.
2. В каждой раскрытой карточке теперь 9 Live-показателей:
   - дистанция;
   - текущая скорость;
   - максимальная скорость;
   - пульс;
   - торможения;
   - спринты;
   - общее время;
   - нагрузка;
   - взрывные действия (ускорения + торможения + спринты).
3. Красные предупреждения показываются счётчиком прямо на карточке игрока.
4. Справа в полноразмерном окне постоянно отображается «Лента моментов»:
   - GPS-предупреждения;
   - спринты;
   - ускорения;
   - торможения;
   - высокая скорость и другие интенсивные события.
5. Сверху ленты есть компактная статистика по типам событий и красным предупреждениям.
6. Нажатие на момент открывает подробный экран нужного игрока и подсвечивает выбранную точку на поле.
   Кнопка «назад» возвращает к сетке карточек и ленте моментов справа.
7. Исправлен счётчик игроков в заголовке подробного просмотра: больше нет жёстко заданного «12 игроков».
