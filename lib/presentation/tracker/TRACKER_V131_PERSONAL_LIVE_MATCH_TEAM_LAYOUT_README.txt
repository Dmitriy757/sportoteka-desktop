Sportoteka Tracker V131 — Personal Live: Team Live layout match

Изменено только представление личных Live-тренировок тренера.

- Убрана большая центральная dashboard-область.
- Слева одно рабочее окно, как в командном Live.
- Внутри рабочего окна переключение «Карта / Пульс».
- Справа постоянная колонка.
- Справа переключение «Данные / Журнал».
- «Данные» показывают текущие показатели личной Live-тренировки.
- «Журнал» показывает Live-события выбранной личной тренировки.
- Нажатие на событие автоматически переводит левое окно в «Карта» и выделяет точку события.
- Возврат «В LIVE» оставляет одну понятную точку возврата.
- Серверные endpoint, GPS/Polar-сбор и расчёты не менялись.
