SPORTOTEKA TRACKER V125 — TACTICAL PRO / 3D LIVE / ANALYTICS
==============================================================

Что добавлено в Live+
---------------------
1. Тактические линии команды:
   - линия обороны;
   - линия полузащиты;
   - линия атаки;
   - расстояния защита→полузащита и полузащита→атака;
   - автоматическое определение примерной формации.

2. Тактический радар в реальном времени:
   - ширина команды;
   - глубина команды;
   - компактность;
   - площадь командного контура;
   - средний интервал до ближайшего партнёра;
   - высота линии обороны;
   - положение центра команды по длине поля;
   - баланс по ширине;
   - распределение игроков левый/центр/правый коридор;
   - распределение по своей/средней/финальной трети;
   - средняя скорость и количество игроков 18+ км/ч;
   - автоматические предупреждения о больших разрывах, растянутой структуре,
     больших интервалах и перегрузе фланга.

3. Тактические слои карты:
   - внешний контур команды;
   - сеть ближайших связей и тактические треугольники;
   - Voronoi-зоны пространственного контроля игроков;
   - центр команды;
   - направляющие ширины/глубины;
   - трети и коридоры поля;
   - красные/оранжевые Live-события;
   - тепловая карта, трек, скорость, пульс, нагрузка и др.

4. Офсайд-ориентир:
   - отображается отдельной линией;
   - направление атаки можно переключать вправо/влево;
   - это ТРЕНИРОВОЧНЫЙ ОРИЕНТИР линии обороны, а не официальное решение
     по офсайду. Для реального определения офсайда нужны синхронные данные
     соперника + мяча/момента передачи (или видео/трекер мяча).

5. 2D / 3D Tactical View:
   - 3D — перспективная визуализация той же калиброванной GPS-карты;
   - HUD, журнал и элементы управления остаются плоскими и читаемыми;
   - GPS остаётся двумерным, высота игрока не выдумывается.

6. GPS Match Replay в Live+:
   - -10 сек / +10 сек;
   - play/pause;
   - 0.5x / 1x / 2x / 4x;
   - переход к моменту из журнала;
   - возврат кнопкой «В LIVE»;
   - во время просмотра прошлого сама Live-запись продолжает работать.

7. Обычная Live-карта:
   - тактические слои теперь доступны и через меню «…» без входа в Live+:
     контур, сеть связей, линии, офсайд-ориентир, зоны контроля, центр и зоны поля.

Что добавлено в Аналитику
-------------------------
Переключатель «Тактика» на командной карте теперь показывает:
- командный контур;
- сеть ближайших связей;
- пространственные Voronoi-зоны;
- центр команды;
- линии обороны / полузащиты / атаки (если позиции игроков известны);
- формацию;
- ширину × глубину;
- средний интервал между игроками;
- расстояния между линиями.

Проекция
--------
Live-аватары, tactical overlays и события сначала используют калибровку поля
через TrackerPitchProjector. Если калибровка недоступна, остаётся fallback
по GPS bounds. Это уменьшает расхождение между аватаром, линиями и точкой события.

Сервер
------
Для V125 новых PHP endpoint/SQL не требуется. Используются уже добавленные ранее
Live events / GPS данные.

Проверка сборки
---------------
В среде подготовки архива Flutter SDK/Dart SDK отсутствуют, поэтому полноценный
flutter build здесь не выполнялся. Перед установкой версия проверена структурно,
а архив — на целостность. Если компилятор на вашем Mac покажет конкретную строку,
пришлите её — исправление можно внести точечно без отката функций.
