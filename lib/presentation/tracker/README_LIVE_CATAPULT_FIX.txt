Sportoteka Tracker Pro — Live Catapult fix

Что исправлено в этом пакете:

1) Убран лишний верхний синий navbar
- Панель Live Center / Analytics / Quality Control / Process / System удалена из рабочего Live-окна.
- Оставлена компактная рабочая шапка Sportoteka: команда, статус Live, GPS, трекер, старт/стоп и периоды.

2) Новый рабочий layout под ПК/планшет
- Поле вынесено в правую большую часть экрана.
- Слева сверху добавлена строка онлайн-показателей в стиле Catapult: скорость, дистанция, м/мин, нагрузка, MAX, время, HIR, VHIR, SPR, ACC, DEC, COD.
- Командная таблица и активные игроки больше не сжимают поле.
- На мобильном порядок упрощён: шапка → показатели → поле → таблица → игроки.

3) Онлайн-данные больше не берутся только с сервера
- Если сервер возвращает нули по HIR / VHIR / SPR / load / m/min, экран подставляет локально рассчитанные значения из текущего RuntimeTrack.
- Для накопительных значений используется максимум между локальными и серверными данными, чтобы серверный MAX 45.8 не затирался локальным ограничением.
- М/МИН теперь рассчитывается даже если сервер не вернул meterage_per_min, но есть дистанция и время Live.

4) Разворот поля обновляется онлайн
- Диалог «развернуть» теперь обновляется таймером каждые 500 мс.
- Больше не нужно вручную обновлять экран, чтобы увидеть движение точки / теплокарту / GPS age в развернутом поле.

5) Сессия сохраняется надёжнее
- Перед остановкой Live Flutter дополнительно сохраняет финальный снимок метрик через save_tracker_metric_snapshot.php.
- В snapshot добавлены HIR, VHIR, Sprint, ACC, DEC, COD, football movement score, metabolic proxy и флаги is_final / created_from_live.
- После этого вызывается stop_tracker_live_session.php с create_final_session=1.

6) Модель LiveState усилена
- TrackerLiveSessionModel теперь умеет читать показатели не только из корневых полей JSON, но и из analysis_json / analysis / metrics.
- Это важно, если PHP сохраняет все метрики внутри analysis_json, а get_tracker_live_state.php не разносит их по отдельным колонкам.

Важно для сервера:
Если PHP save_tracker_live_point.php и get_tracker_live_state.php всё ещё сохраняют/возвращают только latitude, longitude и speed_kmh, то после перезагрузки часть показателей снова будет приходить нулями. В этом пакете Flutter уже отправляет полный payload, но сервер должен принимать и отдавать эти поля.
