SPORTOTEKA TRACKER — V116 LIVE CARDS + EVENTS
Дата: 2026-08-15

Что изменено во Flutter-коде:
1. Кнопка «Все карточки» больше не заменяет весь экран сеткой.
   Открывается аккуратная правая Live-панель, карта/поле остаётся видимой слева.
2. Игроки идут вертикальной лентой. Для каждого показываются:
   - дистанция;
   - текущая скорость;
   - максимальная скорость;
   - торможения;
   - спринты;
   - общее время;
   - нагрузка;
   - взрывные действия (ускорения + торможения + спринты).
3. На карточках появился счётчик красных предупреждений.
4. Внизу панели появился журнал «Моменты и красные точки».
   События идут по времени и открываются нажатием.
5. Добавлена сводка по моментам: красные, GPS, спринты, ускорения,
   торможения, выход на 30+ км/ч.
6. Нажатие на момент выбирает игрока и подсвечивает соответствующую
   красную/оранжевую точку на карте.
7. Live-события подгружаются с PHP инкрементально вместе с основным polling.
8. В PHP отправляются raw GPS-координаты и признак принятия точки в метрики,
   чтобы отфильтрованный GPS-скачок не терялся как диагностическое событие.

Изменённые Flutter-файлы:
- tracker_live_panel.dart
- models/tracker_live_models.dart
- services/tracker_live_api.dart
- services/team_tracker_live_coordinator.dart
