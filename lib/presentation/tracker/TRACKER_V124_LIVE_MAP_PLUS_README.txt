SPORTOTEKA TRACKER V124 — LIVE MAP+

Добавлено:
1. Кнопка ⛶ на общей Live-карте открывает расширенный режим Live+.
2. В Live+ карта занимает основную рабочую область, справа остаётся компактный «Игроки / Журнал» (по входу сразу открыт Журнал).
3. Журнал можно свернуть отдельной полупрозрачной кнопкой — карта получает всю ширину рабочего окна.
4. Под большой картой всегда остаётся линия ПРЯМОЙ ЭФИР / ПРОСМОТР МОМЕНТА:
   - выбор события в журнале переносит всю команду на этот момент;
   - Live-запись продолжает работать;
   - «В LIVE» возвращает к текущим координатам.
5. На карте в реальном времени отображаются красные/оранжевые моменты из текущего Live-журнала.
6. Добавлены полупрозрачные HUD-переключатели прямо на карте:
   - Игроки / аватары;
   - Имена и номера;
   - Связи игроков;
   - Моменты;
   - Трек;
   - Тепло;
   - Скорость;
   - Пульс;
   - Нагрузка;
   - Дистанция;
   - Спринты.
7. Для игрока поверх поля выводится компактная полупрозрачная карточка с включёнными показателями.
8. В режиме просмотра прошлого скорость, дистанция, нагрузка и спринты берутся из снимка трека на выбранный момент; пульс берётся из локальной HR-истории на ближайшее время до момента, если такая история есть.
9. Готовые режимы HUD:
   - Чистая карта;
   - Тактика;
   - Физика;
   - События;
   - Всё Live.
10. Кнопка справа сверху закрывает Live+ и возвращает обычный Live-экран без остановки сессии.

PHP: без изменений относительно V120/V122.
