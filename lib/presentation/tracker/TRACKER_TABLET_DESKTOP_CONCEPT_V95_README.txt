SPORTOTEKA TRACKER — TABLET / DESKTOP CONCEPT V95
=================================================

Основа: Mobile Concept V94. Мобильная логика и BLE/API сохранены.
Цель V95: полностью перевести планшетную и desktop/PC версию Tracker на
единый светлый концепт SPORTOTEKA с зелёным акцентом, как в согласованных
макетах от 12.08.2026.

ОСНОВНАЯ НАВИГАЦИЯ
------------------
• Обзор
• Live
• Аналитика
• Игроки
• История
• Устройства
• Поле
• Личные
• Настройки

ПЛАНШЕТ
-------
• стартовый экран режима: Командный LIVE / Личный LIVE / История;
• пошаговая готовность: режим → устройства → игроки → Live → аналитика;
• подключение GPS + Polar в split-view;
• выбор игроков с реальными avatarUrl из данных SPORTOTEKA;
• Live: поле/тепловая карта + KPI + список игроков;
• поле: avatar-маркеры игроков поверх CustomPainter;
• нагрузка команды / HR zones / speed zones;
• карточка выбранного игрока с live KPI и графиком;
• аналитика и отчёты в единой белой визуальной системе;
• история/календарь с карточками сессий;
• компактная боковая навигация без мобильного Dock.

DESKTOP / MAC / WINDOWS / LINUX
------------------------------
• тёмная левая rail-навигация при ширине >= 1180 px;
• светлая многоколонная рабочая область;
• Обзор рабочего пространства с readiness/KPI/быстрыми действиями;
• Устройства: GPS/Polar, статусы, игроки, назначение и детали;
• Игроки: фото, статус подключения, карточки и фильтры;
• Live Center: поле, команда, KPI, управление сессией;
• split-view: поле + выбранный игрок + графики;
• Аналитика: скорость / ЧСС / нагрузка / спринты / зоны;
• История / календарь;
• Отчёты / экспорт;
• Настройки и сервисные действия.

ВАЖНО
-----
1. Серверные PHP/API файлы не переписаны под дизайн.
2. BLE / GPS / Polar логика сохранена из V94.
3. Фотографии игроков берутся из реальных avatarUrl/данных приложения.
4. Макет-изображение не используется как bitmap-фон: интерфейс реализован
   Flutter-виджетами, чтобы все элементы оставались интерактивными.
5. Flutter SDK отсутствует в среде сборки архива, поэтому после замены папки
   обязательно выполнить flutter analyze / flutter build macos на проекте.
