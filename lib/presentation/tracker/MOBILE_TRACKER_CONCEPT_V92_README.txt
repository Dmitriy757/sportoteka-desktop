SPORTOTEKA — Mobile Tracker Concept V92
Дата: 2026-08-12

Назначение
==========
Это полная папка tracker/ для замены текущей папки модуля Tracker.
Основная цель версии — привести мобильный Tracker к утверждённому белому концепту,
а не только изменить цвета отдельных карточек.

Главные изменения мобильной версии
==================================
1. Один нижний интерфейс вместо «меню над меню».
   При открытии Tracker из Club Workspace мобильный Tracker выводится поверх
   корневого интерфейса приложения и перекрывает глобальный Dock CMR.
   Внутри Tracker остаётся только собственная навигация:
   Поле · Игроки · LIVE · Нагрузка · Меню.

2. Отдельный полноэкранный мобильный Tracker.
   Белый фон, компактная верхняя шапка, явная кнопка закрытия X.
   Начальный экран выбора режима: Командный LIVE / Личный LIVE / История.

3. Новый экран Игроки.
   Сетка игроков с фото, номером, статусом GPS/Polar и зелёным состоянием готовности.
   Быстрый переход в Датчики и Live.

4. Новое подключение устройств.
   Пошаговый сценарий Игрок → GPS → Polar → Live.
   Radar/pulse-анимация поиска, анимированное появление найденных устройств,
   индикатор подключения и состояния готовности.
   После назначения GPS на телефоне сценарий автоматически ведёт к Polar.

5. Новый мобильный LIVE.
   Большая командная сводка: дистанция, средняя скорость, спринты, средняя ЧСС,
   нагрузка и режим. Крупная кнопка Старт/Стоп.
   Подробная карточка выбранного игрока с фото, номером, скоростью, дистанцией,
   спринтами, ЧСС, максимальными значениями и нагрузкой.

6. Поле Live.
   GPS-позиции игроков отображаются аватарками поверх поля.
   Маркеры плавно перемещаются, выбранный игрок выделяется зелёным,
   рядом доступна текущая скорость.

7. Новые графики Live.
   Более высокий интерактивный график ЧСС/скорости/нагрузки.
   Зоны ЧСС и скоростные пороги, подсветка диапазонов, курсор по тапу/свайпу,
   маркер ближайшей точки и текущее значение.

Сохранено без переписывания серверной логики
===========================================
- API и PHP endpoints
- GPS/BLE transport
- Polar/H10 transport
- сохранение Live-сессий
- серверные модели и существующая аналитика
