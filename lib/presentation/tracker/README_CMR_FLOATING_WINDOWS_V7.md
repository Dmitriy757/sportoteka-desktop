# Tracker CMR Clean Window V7

Изменения:
- Убраны дублирующиеся кнопки развернуть/закрыть в плавающих окнах.
- Управление плавающим окном оставлено только в одной верхней строке: закрыть, свернуть, развернуть.
- Внутри открытого плавающего окна скрываются внутренние кнопки повторного открытия этого же блока.
- Кнопки расширения на Live-панелях сделаны серыми круглыми, без чёрных/зелёных стрелок.
- Иконка типа окна в заголовке плавающего окна также сделана в сером круге.
- Нижняя кнопка общего разворота окна трекера приведена к круглому CMR-стилю.
