SPORTOTEKA TRACKER UX V81

Изменения относительно V80:

1. Предпросмотр сессии больше не показывает карточки «N игроков без имени».
2. Список сессий запрашивает расширенный состав участников.
3. Парсер поддерживает players, participants, session_players, members,
   player_ids, participant_ids, player_names и JSON/строковые варианты.
4. Участники сопоставляются с составом команды по всем известным ID и ФИО.
5. В карточках игроков отображаются фотографии из состава; при ошибке загрузки
   остаются инициалы.
6. Кнопка в шапке сокращена до «Выбор сессии».
7. В шапке аналитики убраны рамки и тени активных вкладок — стиль совпадает
   с плоской шапкой Live.

Логика BLE, Polar, скоростей и сохранения Live-сессий не изменялась.
