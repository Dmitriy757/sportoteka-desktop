# SPORTOTEKA Tracker V169 — Personal Live карта/спутник + остановка повторной загрузки аналитики

Дата: 20.08.2026
База: текущий V168/V169 UX workspace.

## 1. Личные тренировки → Live

- В Live-карте личной тренировки используется реальная географическая позиция GPS игрока.
- Маркер игрока обновляется по последней GPS-точке, показывает имя/аватар и следует за игроком.
- Прямо на карте всегда виден переключатель **Карта / Спутник**.
- Старое «Поле» из переключателя личного outdoor Live убрано, чтобы не перегружать интерфейс.
- При отсутствии GPS показывается понятный статус ожидания первой точки; при наличии точки WebView сразу переключается на географическую карту.
- Расширенное Live-окно игрока защищено от параллельных 1-секундных refresh-запросов, чтобы старые ответы не откатывали карту/метрики.

## 2. Аналитика — исправлена повторная/бесконечная загрузка выбранной сессии

Были две причины повторных циклов:

1. Один выбор сессии менял внутренний `_selectedSessionIds`, затем родительский экран возвращал ту же `selectedSession`. Из-за дублирующего id в request key и второго `_reload++` запускался ещё один полный запрос.
2. Recovery heartbeat (`жду переподключение`, `жду finished-файл`, `пауза`) приходил примерно каждые 15 секунд и каждый раз увеличивал `_trackerDataRevision`. Analytics Suite воспринимал это как изменение GPS-данных и сбрасывал уже загруженный bundle.

Теперь:

- внутренний выбор сессии даёт только один цикл загрузки;
- зеркальный `selectedSession` от родителя не меняет bundle key;
- `_trackerDataRevision` меняется только когда recovery действительно финализировал данные (`GPS восстановлен` / `GPS recovery готов`);
- waiting/reconnect/paused сообщения обновляют только статус и лог, но не перезагружают аналитику.
