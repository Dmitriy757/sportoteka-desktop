# Tracker V187 — Матч сразу открывает полный разбор

Изменения в аналитике карты:

- Пункт **«Матч»** в меню карты используется как прямой вход в полный экран повтора/разбора матча (`initialMatchMode: true`). Отдельного промежуточного режима матча в обычной карте не добавляется.
- В полном разборе нижняя кнопка **«К карте аналитики»** теперь закрывает полный экран и переводит CMR-навигацию сразу в **«Обзор»** аналитики.
- Возврат выполняется через существующий `onBackToAnalyticsMenu`, поэтому восстанавливается обычное левое меню аналитики и выбирается индекс обзора.
- ИИ/Видео по-прежнему закрывают inspector своим отдельным `onDismissForAction`; их поведение не изменено.
- Крестик полного окна также не менялся этим патчем.

Основной изменённый файл:
`widgets/tracker_action_analytics_suite.dart`
