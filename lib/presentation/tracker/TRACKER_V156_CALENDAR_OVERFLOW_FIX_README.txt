SPORTOTEKA TRACKER V156 — CALENDAR OVERFLOW FIX
================================================

Исправлена Flutter rendering error:
`A RenderFlex overflowed by 38 pixels on the bottom`
в `tracker_action_analytics_suite.dart`.

Причина: календарь с шестью строками в режиме roomy всегда требовал минимум
42 px на ячейку. Вместе с пятью промежутками по 7 px получалось 287 px при
доступных 249 px.

Теперь при ограниченной высоте размер календарной ячейки рассчитывается по
реальному `LayoutBuilder.maxHeight`. Для 249 px итоговая сетка занимает ровно
249 px. В прокручиваемом мобильном календаре прежний крупный размер сохранён.

V156 также содержит все исправления V155 по BLE reconnect и восстановлению
пропущенных GPS-точек.
