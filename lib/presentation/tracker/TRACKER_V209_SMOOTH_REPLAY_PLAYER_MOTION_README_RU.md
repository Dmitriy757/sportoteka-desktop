# TRACKER V209 — плавное движение игроков в Replay / Аналитике

Изменения:

- Полный Replay матча: аватары игроков теперь плавно анимируются между кадрами таймлайна (`AnimatedPositioned`, 210 мс, linear).
- Обычная аналитика Маршрут/Запись: зелёный курсор вынесен в отдельный плавно анимируемый слой, без увеличения частоты перестроения всего тяжёлого экрана.
- 2ГИС и Спутник в архиве: текущая позиция рассчитывается интерполяцией внутри соседних GPS-точек, а затем маркер плавно перемещается через `requestAnimationFrame`.
- При ручной перемотке ползунка плавность выключается: выбранный момент показывается сразу и точно.
- При Play плавность включается автоматически.
- На GPS-разрывах более 15 секунд интерполяция не строит ложный путь: маркер удерживается на последней подтверждённой позиции до появления следующей валидной точки.
- Live-сглаживание из V208 сохранено без изменений: 780 мс.
- Исходные GPS-точки, дистанция, скорость, события и серверная аналитика не изменяются — сглаживание остаётся визуальным.

Основные файлы:

- `widgets/tracker_action_analytics_suite.dart`
- `widgets/tracker_2gis_map_layer.dart`
