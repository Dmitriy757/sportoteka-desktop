# TRACKER V180 — inline рейтинг + радар/сводка

Что изменено по последней правке:

- кнопка **«Рейтинг дня»** больше не открывает отдельную внешнюю панель поверх интерфейса;
- на desktop/tablet рейтинг теперь открывается **внутри окна трекера**, справа, как встроенная CMR-панель;
- в компактной ширине встроенный рейтинг открывается отдельным нижним блоком внутри текущего окна;
- в обзоре убрана **мини-теплокарта**;
- обзор собран в логике **двух основных блоков**:
  - **слева** — «Радар выбранной сессии»;
  - **справа** — «Командная сводка»;
- при открытии рейтинга справа появляется третья встроенная панель без выхода за пределы workspace;
- в блоке радара вместо мини-теплокарты теперь сделана **сводка сессии** с ключевыми метриками;
- добавлены фирменные **CMR-точки** в зоне сводки сессии и сохранён dot-accent в заголовках;
- стандартные иконки в обзорных карточках и кнопках немного уменьшены.

Основной изменённый файл:

- `widgets/tracker_action_analytics_suite.dart`
