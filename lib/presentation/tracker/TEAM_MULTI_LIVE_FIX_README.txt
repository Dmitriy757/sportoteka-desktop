СПОРТОТЕКА — командный Live v51

Установка:
1. Скопировать содержимое этой папки в /api/tracker/ на сервере.
2. Обязательно загрузить новый файл start_team_tracker_live_sessions.php.
3. SQL вручную выполнять не требуется.

Что исправлено:
- один запрос запускает до 32 GPS-трекеров команды;
- для каждого игрока создаётся отдельная tracker_live_sessions;
- запуск выполняется транзакционно, без частично запущенной команды;
- незаполненный player_id восстанавливается по подтверждённому назначению клиента;
- Polar H10 больше не блокирует назначение GPS тому же игроку;
- MAC и iOS UUID одного $ATP объединяются по имени устройства.

Перед стартом в приложении каждому GPS должен быть выбран игрок, а сам GPS
должен показываться подключённым. После этого одна кнопка «Старт» запускает
все подключённые и назначенные GPS-трекеры.
