# Sportoteka Tracker — CMR clean window v2

Что изменено:

- Убрана верхняя внутренняя шапка Tracker Pro: теперь экран собран как CMR Trainers/Teams — левая колонка навигации, тонкий разделитель, правая рабочая область.
- В embedded-режиме больше нет ощущения «окно внутри окна»: одна общая светлая поверхность, аккуратная внешняя рамка и только тонкие линии между зонами.
- Добавлена общая кнопка развернуть/свернуть внизу справа у всего окна трекера.
- Live: удалён широкий декоративный таймлайн с оранжевой полосой и фейковыми периодами.
- Live: добавлена компактная строка состояния с реальным временем Live и мини-линией нагрузок по точкам GPS.
- Маркеры мини-линии: HIR / VHIR / SPR / ускорения / торможения по фактическим RuntimePoint.
- Поле Live стало крупнее: таблица снизу уменьшена, лишние шапки сняты.
- Шрифт во всех ключевых CMR-окнах трекера уменьшен и приближен к Teams/Trainers.
