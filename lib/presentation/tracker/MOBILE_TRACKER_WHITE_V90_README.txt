SPORTOTEKA TRACKER — MOBILE WHITE V90
Дата: 2026-08-12

Что изменено в мобильной версии (<720 px)

1. Полноэкранный мобильный shell
- единый белый Tracker Workspace;
- верхняя компактная шапка «ТРЕКЕР»;
- статус LIVE / ГОТОВ / OFF;
- отдельная кнопка X для безопасного выхода;
- убран старый резерв 118 px под внешний Dock;
- одинаковый mobile shell используется и для standalone Tracker route.

2. Новая нижняя навигация
- Поле;
- Игроки;
- центральная крупная кнопка LIVE;
- Нагрузка;
- Меню.

В «Меню» вынесены:
- Личный Live;
- История и отчёты;
- Пороги и настройки;
- Датчики.

3. Live переработан и упрощён
Порядок экрана:
- статус + Старт / Стоп Live;
- выбранный игрок;
- поле;
- интерактивные графики;
- список игроков команды.

Убрана промежуточная мобильная полоса «Игроки / Карта / Анализ» из основной ленты.
Переходы между разделами получили Fade + Slide animation.
Карточки появляются с мягкой reveal-анимацией.

4. Поле Live
- сохранён существующий CustomPainter поля, GPS-треков и heatmap;
- поверх него добавлены реальные Flutter-аватарки игроков;
- аватар плавно перемещается между GPS-точками;
- выбранный игрок выделяется зелёным кольцом;
- под аватаром показывается текущая скорость;
- тап по аватару выбирает игрока;
- переключатель «Метки» включает/выключает аватарки.

5. Графики
- вместо маленького 74 px preview сделан полноценный Live-блок;
- переключение: Пульс / Нагрузка / Скорость;
- для пульса используются Z3/Z4/Z5;
- для скорости — HIR / Sprint thresholds;
- переключение графика анимировано;
- подробный анализ остаётся доступен через существующую аналитику.

6. Подключение GPS / Polar
- сохранена существующая BLE-логика и назначения игроков;
- шаги Игрок → GPS → Polar теперь анимированы;
- завершённый шаг превращается в зелёную галочку;
- при сканировании GPS/Polar вместо обычного spinner используется radar-анимация;
- главные мобильные кнопки увеличены и сделаны более выраженными.

7. Общий mobile UI
- радиусы мобильных карточек увеличены;
- лёгкие тени без тяжёлых рамок;
- крупнее touch targets;
- primary actions на телефоне — сплошной зелёный;
- планшетная и desktop логика сохранены отдельно.

Файлы с основной переработкой:
- tracker_live_panel.dart
- screens/tracker_match_workspace_screen.dart

Backend / API
PHP/API-файлы, серверные Live-сессии, BLE protocol, GPS filtering, Polar upload и логика сохранения не менялись.

Проверка архива
- выполнена проверка баланса Dart (), [] и {} в изменённых файлах;
- выполнен git diff --check;
- Flutter SDK в среде сборки архива отсутствует, поэтому flutter analyze / flutter build здесь не запускались.

Архив содержит полную папку tracker/ и предназначен для полной замены текущей папки после резервной копии.
