SPORTOTEKA TRACKER V123 — LIVE VIEW SETTINGS

Добавлено:
1. Кнопка настройки вида Live (иконка sliders/tune) в верхней панели рядом с BLE/GPS reset.
2. Окно «Настройка Live-экрана» с мгновенным управлением выводом:
   - карточки игроков сверху;
   - правая рабочая панель;
   - линия прямого эфира;
   - командные KPI под полем;
   - аватарки игроков на поле;
   - связи игроков на поле.
3. Для правой панели можно сразу выбрать стартовый режим:
   - Игроки Live;
   - Журнал моментов.
4. Если правая панель скрыта, карта автоматически занимает освободившуюся ширину.
5. Если скрыты верхние карточки / timeline / KPI, поле автоматически получает освободившуюся высоту.
6. Настройки меняют только визуальный вывод. GPS / BLE / Polar / серверная Live-сессия продолжают собирать данные.
7. Кнопка подсвечивается зелёной точкой, если вид отличается от стандартного.
8. «По умолчанию» возвращает полный Live-интерфейс.

PHP: без изменений относительно V120/V122.
