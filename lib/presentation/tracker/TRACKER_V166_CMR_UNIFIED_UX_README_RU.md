# SPORTOTEKA Tracker V166 — CMR Unified UX

Дата: 20.08.2026
База: V165 AUTO RECOVERY + LIVE PRIORITY

## Цель

Привести Tracker к той же визуальной системе, что `cmr_club_roster_panel.dart`:

- светлый CMR workspace;
- единый Inter / CMR масштаб текста;
- рабочая область слева + постоянная контекстная панель справа;
- единая геометрия: рабочее окно 18–20 px, карточки 16 px, внутренние блоки 12 px;
- фирменные четыре точки SPORTOTEKA;
- меньше декоративных Material-иконок;
- зелёный `#00A750` только как премиальный акцент;
- тонкие разделители `#E9ECEA`, без тяжёлых рамок.

## Какие разделы переведены на двухпанельный CMR layout

На ПК / широком планшете (при достаточной ширине) единый layout применяется к:

1. **Аналитика**
   - слева остаётся полноценная текущая аналитика: карта, графики, таймлайн, календарь и т.д.;
   - справа: выбранная сессия, ключевые показатели, состояние GPS/Polar, локальные точки, ATP archive, Recovery;
   - быстрые действия: Live и ручное восстановление GPS.

2. **Датчики**
   - слева текущий рабочий экран подключения/таблица устройств;
   - справа: состояние команды, выбранный игрок, GPS/Polar, пульс, Recovery и очередь каналов;
   - кнопки поиска и Recovery.

3. **Игроки**
   - слева состав;
   - справа контекст выбранного игрока, датчики, пульс, состояние команды, поле и выбранная аналитическая сессия;
   - переходы в аналитику и датчики игрока.

4. **Личная тренировка**
   - слева существующий personal training workspace;
   - справа выбранный игрок, датчики, состояние полного матча, автозагрузка и Recovery;
   - быстрые переходы Live / Аналитика.

5. **Настройки**
   - слева существующие настройки порогов и системы;
   - справа системный CMR-инспектор: команда, устройства, поле, калибровка, Recovery и параметры концепции интерфейса.

На телефоне и узком планшете правый inspector автоматически скрывается, чтобы не уменьшать рабочую область.

## Навигация

- На desktop компактная icon-only rail заменена на широкую CMR-панель с названиями разделов.
- В основной навигации вместо отдельной иконки каждого раздела используются фирменные точки SPORTOTEKA.
- На планшете остаётся компактная rail, но также с фирменным dot-cluster.
- В аналитике desktop/tablet tabs используют маленькую фирменную точку вместо набора разнотипных иконок.
- В личных тренировках основные tabs используют точки.
- В списке игроков/датчиков часть декоративных иконок заменена статусными точками.
- Иконки сохранены там, где они реально обозначают действие (закрыть, поиск, системные controls, специализированные инструменты карты и т.п.).

## Что НЕ менялось

V166 — UX/визуальный слой поверх V165. Не удалялись и не откатывались изменения V165:

- автоматическое восстановление полного матча;
- Recovery после Stop;
- пауза BLE Recovery во время нового Live;
- возможность запуска новой сессии при восстановлении предыдущей;
- защита от частичного ATP upload;
- восстановление pending/waiting задач;
- lifecycle BLE fixes;
- исправление RenderFlex V159.

Серверные API и структура БД в V166 не менялись.

## Установка

Архив содержит полный каталог `tracker/`.

Заменить каталог:

`lib/presentation/tracker/`

на каталог `tracker/` из архива (предварительно сохранить резервную копию своего текущего каталога).

После замены:

```bash
flutter clean
flutter pub get
flutter analyze
flutter run
```

Для iOS/macOS при необходимости дополнительно выполнить обычный цикл Pods проекта.

## Рекомендуемая проверка

1. Открыть Analytics на ПК: справа должна появиться CMR context panel.
2. Переключить игрока/сессию — правый контекст должен обновляться.
3. Открыть Датчики и выбрать игрока — справа проверить GPS/Polar.
4. Открыть Игроки — справа должен отображаться выбранный игрок.
5. Открыть Личную тренировку — проверить единый green/soft стиль и tabs с точками.
6. Открыть Настройки — проверить CMR inspector справа.
7. На ширине <1040 px рабочей области right inspector должен исчезать, чтобы не было overflow.
8. Отдельно повторить тест V165: Live → Stop → Recovery → Start нового Live.
