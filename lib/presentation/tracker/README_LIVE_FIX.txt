Sportoteka Tracker Live FIX

Что изменено:
1. BLE-поиск расширен для macOS/DMG: показываются не только $ACT/$ATP/$GPS, но и близкие BLE-кандидаты. Добавлен fallback notify/write характеристик.
2. Парсер Live GPS стал устойчивее: пакеты 3B/44/45 читаются по нескольким offset и масштабам координат.
3. Live теперь отправляет в API не только координату, но и рассчитанные онлайн-метрики: дистанция, скорость, max, м/мин, нагрузка, HIR, VHIR, sprint, ускорения, торможения, смены направления, fatigue, метаболика.
4. Таблица команды читает расширенные поля из get_tracker_live_state.php, если сервер их отдаёт.
5. Точка на поле теперь использует калибровку поля через TrackerPitchProjector и field_x_m / field_y_m, поэтому теплокарта и движение точки должны совпадать с реальным полем.
6. Если команда Live GPS не даёт координату, экран автоматически перебирает кандидаты команд до появления свежего GPS.

Заменить файлы в проекте с сохранением путей:
- tracker/tracker_live_panel.dart
- tracker/models/tracker_live_models.dart
- tracker/models/action_tracker_protocol.dart
- tracker/services/action_tracker_ble_service.dart

Важно:
Если серверные PHP-скрипты пока не сохраняют новые поля, Flutter всё равно покажет локальную аналитику во время Live. Для отображения расширенных метрик на других устройствах/после перезагрузки нужно, чтобы save_tracker_live_point.php сохранял новые поля, а get_tracker_live_state.php возвращал их.
