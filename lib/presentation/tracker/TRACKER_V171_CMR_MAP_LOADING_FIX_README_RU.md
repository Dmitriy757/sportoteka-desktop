# SPORTOTEKA Tracker V171 — CMR cleanup + карты + стабильная аналитика

Дата: 20.08.2026  
База: V170 CMR Layout Cleanup

## Что изменено

### 1. Аналитика больше не должна постоянно перезагружать выбранную сессию
- Архивная выбранная сессия больше не зависит от `workspace.localPoints.length`.
- Фоновые Live/recovery GPS-точки не пересоздают `FutureBuilder` открытой архивной аналитики.
- Recovery status больше не увеличивает `dataRevision` на каждом промежуточном сообщении/проценте.
- Обновление карты/аналитики после recovery выполняется debounce-ом после затихания потока статусов.
- Auto Recovery полного матча и обновление после догрузки сохранены.

### 2. Личная тренировка → Live: настоящая карта и спутник
Файл: `player/player_my_trainings_screen.dart`

В Live добавлен отдельный выбор подложки:
- Поле / схема;
- Карта 2ГИС;
- Спутник.

Для Карты/Спутника используется существующий `Tracker2GisMapLayer`:
- текущая позиция игрока;
- маршрут;
- имя/аватар;
- follow latest в Live;
- интерактивная карта.

При выборе «Тепло» интерфейс автоматически возвращается на схему поля, потому что heatmap рисуется Flutter painter-слоем.

### 3. Аналитика → Карта: Карта/Спутник прямо в основном окне
- В обычной карте аналитики теперь тоже есть переключение `Поле / Карта / Спутник`.
- Не нужно обязательно открывать отдельный expanded inspector, чтобы увидеть дома/дороги/спутник.
- На географической подложке отображается маршрут выбранных игроков и текущая точка playback.

### 4. «Расширить» заменено на «Подробнее»
В основном toolbar карты теперь используется более понятная кнопка `Подробнее`.

### 5. Данные карты собраны аккуратнее
- Убраны пять KPI из перегруженного toolbar над картой.
- Toolbar теперь отвечает только за режим карты, фильтры, подложку и `Подробнее`.
- Справа добавлена компактная CMR-полоска основных данных:
  - дистанция;
  - максимальная скорость;
  - спринты;
  - события.
- Сохранены вкладки `График / События / Сессия`.
- Toolbar сделан горизонтально прокручиваемым, поэтому не должен снова давать RenderFlex overflow на узкой рабочей области.

### 6. Убраны повторные большие шапки
- `_DarkPage` больше не рисует второй заголовок раздела на desktop/tablet.
- Если у раздела есть действия, остаётся только тонкая строка кнопок.
- В CMR split-workspace удалена отдельная 60 px шапка `Аналитика / Игроки / Датчики / ...`.
- Полезное содержимое начинается выше: выбор сессии/подразделы сразу после левой rail-навигации.

### 7. Игроки стали компактнее
- Карточки состава уменьшены по высоте.
- Аватары немного уменьшены.
- Убрана лишняя нижняя линия обычной карточки.
- Больше игроков помещается на одном экране без ощущения огромных пустых блоков.

### 8. Поле стало легче
- Убрана ещё одна повторная GPS/status-плашка над картой калибровки.
- Для уже сохранённой калибровки не показывается длинная повторная подсказка.
- Шапка `Калибровка по 4 точкам` заменена на компактную строку `Калибровка A / B / C / D`.
- Карта получила больше вертикального места.
- Карточки полей компактнее и без постоянной нижней линии.

### 9. Шрифт CMR Roster
Основное desktop/tablet окно Tracker обёрнуто в `AppTypography` scope. Явные размеры/цвета компонентов сохраняются, а семейство шрифта наследуется из общей системы SPORTOTEKA/CMR.

## Быстрый тест
1. Аналитика → выбрать одну сохранённую сессию → подождать 1–2 минуты: экран не должен циклически возвращаться к loader.
2. Во время фонового GPS Recovery держать старую сессию открытой: промежуточные recovery status не должны пересоздавать аналитику на каждом сообщении.
3. Личные тренировки → Live → карта: переключить `Карта`, затем `Спутник`; игрок и маршрут должны отображаться поверх географической подложки.
4. Аналитика → Карта: проверить `Поле / Карта / Спутник`.
5. Проверить `Подробнее` вместо `Расширить`.
6. Игроки: убедиться, что карточки выше не раздуваются и больше игроков помещается в сетку.
7. Поле: сохранённая калибровка должна занимать меньше вертикального места, карта — больше.

## Важно
Flutter SDK в среде сборки архива недоступен, поэтому здесь выполнена структурная проверка изменённых Dart-файлов и проверка баланса скобок, но не `flutter analyze/build`. После замены папки рекомендуется запустить:

```bash
flutter analyze
flutter run -d macos
```
