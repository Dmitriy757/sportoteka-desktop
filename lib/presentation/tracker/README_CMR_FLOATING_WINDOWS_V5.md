# Tracker CMR Floating Windows V5

Изменения:
- Левое меню остаётся компактным.
- Live-блоки «Поле», «Командная таблица», «Активные игроки», «Оператор» теперь открываются как внутреннее плавающее окно.
- У плавающего окна есть управление как у macOS/desktop: закрыть, свернуть, развернуть/вернуть размер.
- При сворачивании появляется компактная плашка внизу слева; её можно нажать для восстановления.
- Основной экран Live остаётся видимым под полупрозрачной подложкой.
- Это заменяет прежнее поведение через обычный Dialog/расширение блока.
