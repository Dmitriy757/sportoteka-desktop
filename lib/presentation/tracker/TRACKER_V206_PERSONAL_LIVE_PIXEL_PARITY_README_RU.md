# V206 — Личные тренировки / Personal Live = Team Live pixel parity

## Что изменено

- Активная личная тренировка на desktop открывается в той же геометрии, что командный Live:
  - адаптивное левое CMR-меню 168/184/200/220/236 px;
  - верхняя control-header 38 px;
  - двухрядная лента активных игроков 112/124 px;
  - карта 62% + правый инспектор 38%;
  - timeline 46/48 px;
  - нижняя KPI-лента 48/50 px.
- Переключение игрока происходит в одной рабочей области: выбрали игрока → поле, карта, спутник, GPS, скорость, Polar и журнал переключаются на него без нового экрана.
- В левом меню используются те же группы, что в Team Live: «Вид и события», «Слои карты», «Подложка».
- Подложки: Поле / Карта / Спутник.
- 3D PRO по умолчанию включён; для поля используется та же камера/джойстик, геометрия и цвета, что в Team Live/карте разбора.
- Поле full-bleed: те же оттенки газона, полосы, разметка и внутренние 10 px.
- На поле отображается аватар выбранного игрока и HUD; их можно отключить слева.
- Правый блок теперь имеет вкладки «Журнал / Скорость / Кардио» в геометрии Team Live/Replay.
- Скорость строится по GPS выбранного игрока с адаптивной вертикальной шкалой.
- Архивная личная сессия на desktop открывается в том же fullscreen-workspace: карта/спутник, timeline, KPI, журнал/скорость/кардио.
- Крестик и нижняя кнопка «К выбору сессий» возвращают к списку личных сессий, а не закрывают Tracker.
- Внешняя аналитика сохранена отдельной кнопкой в header завершённой сессии.

## Данные / сервер

GPS/Polar API, запись Personal Live, recovery и серверные endpoint'ы не менялись. Изменена компоновка и привязка уже полученных данных к выбранному игроку.
