# Tracker — фирменный минимализм Sportoteka

- Белое единое полотно без карточной сетки.
- Нейтральные обводки по периметру удалены.
- Тонкие разделители используются только между смысловыми секциями.
- Основные внутренние отступы: 8–10 px.
- Скругления сохранены только у кнопок, чипов, статусов и модальных окон.
