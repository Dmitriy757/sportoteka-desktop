# SPORTOTEKA Tracker V157 — готовность и управление нагрузкой

## Что добавлено

- Новая вкладка **«Готовность»** в общей и личной аналитике.
- Вкладка расположена непосредственно после **«Обзора»** на компьютере/планшете и вынесена в основную мобильную навигацию.
- В переключателе игроков отображаются клубные аватарки; если фото отсутствует или недоступно, показываются инициалы.
- Суммарная GPS-нагрузка за 7 дней, средняя неделя за 28 дней и тенденция 7/28.
- Изменение к предыдущей неделе, монотонность и strain.
- Ежедневная анкета: сон, качество сна, усталость, мышечная болезненность, стресс, настроение, боль, RPE и комментарий.
- Итоговый статус готовности 0–100 с уровнем уверенности и практическими рекомендациями.
- Скользящие пиковые окна 1, 3, 5 и 10 минут по GPS выбранной сессии.
- Постоянные индивидуальные пороги HIR/спринта и ускорения/торможения.
- Режим порогов от подтверждённого личного максимума: HIR 75%, спринт 90%.
- Собственный эталон матча. Любую выбранную сессию можно отметить кнопкой **«Это матч»**; сравнение считается по реальным матчам игрока, без фиксированного среднего норматива.
- Командный центр готовности: весь состав, статусы, анкеты, нагрузка 7/28 и быстрый переход к игроку на одном экране.
- Одинаковая функция доступна тренеру и игроку в личном кабинете.

## Серверная установка

1. Выполнить `SPORTOTEKA_TRACKER_V157_READINESS_MIGRATION.sql` в базе SPORTOTEKA.
2. Загрузить содержимое `server/api/tracker/` в каталог, на который указывает `TrackerProApi.apiBaseUrl`.
3. Если проект не создаёт глобальный `PDO` через стандартные config-файлы, определить путь к bootstrap базы в `TRACKER_DB_BOOTSTRAP` либо задать `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS` и при необходимости `DB_PORT`.
4. Подключить к новым endpoint тот же middleware авторизации и проверки доступа к клубу/команде, который используется остальными API Tracker.

Endpoint:

- `GET get_tracker_readiness.php?club_id=...&team_id=...&player_id=...&reference_date=YYYY-MM-DD`
- `GET get_tracker_readiness_team.php?club_id=...&team_id=...&reference_date=YYYY-MM-DD`
- `POST save_tracker_readiness.php` с JSON-действием `save_profile` или `save_checkin`.

API дополнительно делает `CREATE TABLE IF NOT EXISTS`, поэтому при наличии у web-пользователя права `CREATE` модуль поднимется и без отдельного запуска миграции. Для production рекомендуется выполнить SQL заранее и оставить приложению только права на данные.

## Важное ограничение

Статус готовности — тренерский индикатор. Он не является диагнозом и не прогнозирует травму. При боли или симптомах решение должен принимать медицинский специалист.
