SPORTOTEKA TRACKER — TABLET / DESKTOP CONCEPT V97
================================================

Цель V97: привести реальный Flutter-интерфейс планшета и ПК к согласованному
белому концепту Tracker, а не оставлять старые desktop/tablet экраны под новой
обёрткой.

КЛЮЧЕВОЕ
- Полностью убрана тёмная/чёрная навигационная rail-панель Tracker.
- Standalone и embedded запуск используют один и тот же светлый shell.
- ПК: светлое левое меню, зелёный активный пункт, компактные рабочие панели.
- Планшет: рабочая область на всю ширину + отдельное нижнее меню Tracker:
  Главная / LIVE / Игроки / Аналитика / История / Устройства / Настройки.
- Глобальный мобильный Dock не является частью этого планшетного меню Tracker.

ПЕРЕРАБОТАННЫЕ ЭКРАНЫ
1. Обзор рабочего пространства
   - статус команды, готовность GPS/Polar, нагрузка, последние сессии,
     быстрые действия.
2. Устройства
   - GPS/Polar в рабочей таблице, игрок с реальным avatarUrl, статус, заряд,
     связь, добавление и сервисные действия.
3. Игроки
   - карточки переработаны в портретный формат концепта: фото по центру,
     номер, позиция, GPS/Polar/HR, online check, зелёный selected-state.
4. LIVE
   - поле/heatmap + KPI + состав справа; tablet/desktop split layout.
5. Аналитика
   - единая светлая палитра, графики и рабочие панели.
6. История / отчёты
   - календарь и список сессий + конструктор отчёта в одном workspace.
7. Поле / калибровка
   - сохранена рабочая GPS-калибровка, приведена к общей светлой системе.
8. Личные тренировки
   - общая палитра и карточки синхронизированы с новым Tracker UI.
9. Настройки
   - профиль/готовность, системные параметры, пороги, пресеты и быстрые действия.
10. PDF / отчёт
   - палитра и геометрия синхронизированы с новым desktop/tablet Tracker.

ВАЖНО
- BLE, GPS, Polar H10, API/PHP и серверная логика не заменялись декоративными
  заглушками. UI использует текущие реальные данные приложения.
- Фото игроков берутся из существующего player.avatar/avatarUrl.
- Мобильная архитектура V94 сохранена; V97 сфокусирована на планшете и ПК.
- В среде подготовки архива отсутствует Flutter SDK, поэтому flutter analyze /
  flutter build здесь не запускались. Выполнена статическая проверка структуры
  всех Dart-файлов и проверка целостности архива.
