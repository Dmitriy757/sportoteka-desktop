SPORTOTEKA TRACKER V143 — PERSONAL MODALS + PLAYER AI MODE

Изменения только для «Мои тренировки» игрока:

1. Модальные окна карты выше на телефоне
   - «График скорости», «События тренировки», «Спринты», «Данные сессии/точки»:
     высота увеличена с 76% до 90% экрана.

2. Модальное окно «СПОРТОТЕКА ИИ» выше
   - высота увеличена с 88% до 94% экрана;
   - уменьшен верхний внешний отступ.

3. Убран «Журнал решений тренера» из личной сессии игрока
   - в player personal mode тренерская оценка/заметка больше не рендерится;
   - ИИ-панель получает всю доступную высоту;
   - в командной аналитике тренерский журнал сохранён без изменений.

4. ИИ явно понимает, что это личная тренировка игрока
   - playerOnlyMode включён для personal session;
   - payload получает scope=personal_training_report и personal_session=true;
   - prompt просит рекомендации игроку, а не «что делать тренеру»;
   - исключены тренерские заметки и командные рекомендации для личной сессии.
