# Tracker V183 — меню карты в левой CMR-панели

Изменены:
- `screens/tracker_match_workspace_screen.dart`
- `widgets/tracker_action_analytics_suite.dart`

Что изменено:
1. В desktop/tablet CMR-аналитике при выборе раздела **Карта** обычное левое меню аналитики скрывается.
2. На его месте появляется меню инструментов карты:
   - Маршрут
   - Тепло
   - Матч / Запись
   - Ghost (для личного режима, если доступен)
   - Пит-уолл
   - Точки (с прежним фильтром всех типов точек)
   - Поле
   - Карта (2ГИС)
   - Спутник
   - Подробнее
3. Горизонтальная строка этих инструментов над картой в таком режиме не дублируется.
4. Внизу левой панели добавлена кнопка **«К списку меню аналитики»** в стиле возврата к списку игроков.
5. Возврат к меню аналитики не сбрасывает выбранную сессию и состояние MapTab.
6. Закрытие развёрнутой карты в новом CMR map-sidebar не выбрасывает пользователя из раздела «Карта».
7. На мобильном интерфейсе прежняя навигация сохранена без изменений.
