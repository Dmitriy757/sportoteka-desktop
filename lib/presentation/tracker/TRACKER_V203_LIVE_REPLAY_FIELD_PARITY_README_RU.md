# TRACKER V203 — одинаковое поле Live и карты разбора

Исправлено расхождение между полем в командном Live и полем в полном разборе матча.

## Что было

Live использовал `_RuntimeFieldPainter`, который вписывал поле 105×68 внутрь доступной области через aspect-ratio. На широком/высоком desktop canvas вокруг поля оставались большие светлые поля. После включения 3D это дополнительно уменьшало поле относительно карты разбора.

Карта разбора использует `_ActionPitchPainter`: газон заполняет весь canvas, а GPS-точки проецируются внутрь игровой линии с отступом 10 px.

## Что изменено

Файл: `tracker_live_panel.dart`

- Live pitch теперь full-bleed, как в карте разбора.
- Убрано отдельное aspect-ratio вписывание 105×68 для визуального canvas.
- GPS, аватары, маршруты, события и тактические слои проецируются внутрь линии поля с отступом 10 px — как в аналитике.
- Цвета газона, полосы, белая разметка, центр и штрафные приведены к `_ActionPitchPainter`.
- Убран светлый grid-фон вокруг поля.
- Убран дублирующий текст с названием/размером поля внутри газона: Live HUD уже содержит служебную информацию.
- Радиус live map canvas приведён к 16 px, как в полном разборе.
- 3D yaw/tilt/zoom не менялись: `_LivePitchPerspective` уже совпадает по параметрам с `_AnalyticsPitchPerspective`.

## Не затронуто

- BLE / GPS приём
- серверные live sessions
- калибровка A/B/C/D
- TrackerPitchProjector
- Replay / журнал
- Polar H10
- 2ГИС / спутник

Калибровка продолжает определять положение игроков на поле. Изменена только визуальная геометрия внутренней подложки Live, чтобы она совпадала с картой разбора.
