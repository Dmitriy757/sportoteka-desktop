# Sportoteka Tracker V160 — плавное рисование в разборе

## Исправлено

- `TgAnalyticsOverlay` больше не пересобирает весь widget tree при каждом
  движении пальца/мыши.
- Контроллер подключён напрямую к `CustomPainter(repaint: controller)`:
  изменение рисунка вызывает только paint слоя аннотаций.
- Карта, GPS-маршрут и игроки изолированы внутренним `RepaintBoundary` и не
  растеризуются заново вместе с каждым штрихом.
- Частые pointer-события объединяются до одного обновления на кадр.
- Свободная линия семплируется с шагом примерно 2.4 экранного пикселя, поэтому
  длинный штрих не создаёт сотни почти одинаковых точек.
- Во время жеста dashed/wavy/zigzag показываются дешёвой сплошной линией;
  выбранный сложный стиль применяется к готовому объекту после отпускания.

## Что сохранено

- угловое масштабирование и вращение объектов;
- Undo / Redo;
- серверное сохранение tactical review;
- одинаковое поведение в Live-разборе и полной аналитике;
- полный recovery матча из ATP и неблокирующий запуск следующего Live из V159.

Миграций БД и изменений PHP в V160 нет.
