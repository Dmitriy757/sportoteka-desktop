# Личные Live — серверное обновление

Добавлены и обновлены PHP API для экрана личных тренировок.

## Новые endpoints

### `player_get_session_heart_rate.php`
Параметры:
- `team_id` — обязательно;
- `session_id` или `live_session_id` — обязательно;
- `player_id` — необязательно.

Возвращает:
- точки Polar с `elapsed_sec` и `minute`;
- разбивку `by_minute`;
- средний, минимальный и максимальный пульс;
- минуту и точное время минимального/максимального пульса;
- начало, окончание и длительность сессии;
- тип и русское название тренировки.

### `player_get_personal_training_stats.php`
Параметры:
- `team_id` — обязательно;
- `player_id`, `date_from`, `date_to` — необязательно.

Возвращает:
- всего тренировок;
- сегодня;
- за последние 7 дней;
- за текущий месяц;
- количество игроков онлайн;
- разбивку по дням;
- разбивку по игрокам;
- список личных сессий.

## Обновлённые endpoints

- `player_get_live_state.php` — ФИО, сокращённое имя, аватар, вид тренировки, длительность и сводка Polar.
- `player_get_training_notifications.php` — ФИО, аватар, начало/окончание, длительность, вид тренировки, флаги перехода в отчёт и аналитику.
- `player_get_sessions.php` — аватар, сокращённое имя, русское название тренировки и поля переходов.
- `player_start_live_session.php` — уведомление сохраняет время начала и тип тренировки.
- `player_tracker_bootstrap.php` — общие функции для аватара, ФИО и русских названий активностей.

Новая миграция не требуется: `elapsed_sec` вычисляется из `measured_at - started_at`, поэтому поддерживаются уже сохранённые Polar-точки.
