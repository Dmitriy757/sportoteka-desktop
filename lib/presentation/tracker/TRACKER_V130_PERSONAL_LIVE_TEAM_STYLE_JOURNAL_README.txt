SPORTOTEKA TRACKER — PERSONAL LIVE TEAM STYLE + JOURNAL

Изменения только для тренерского раздела «Личные тренировки»:

1. Personal Live приведён к логике командного Live.
2. Основная рабочая область — большая центральная панель.
3. В центре есть переключатель «Карта / Пульс» без перехода на другой экран.
4. В режиме «Карта» поверх поля показываются компактные Live HUD-данные:
   дистанция, текущая/максимальная скорость, пульс, спринты,
   ускорения, торможения, взрывные действия, HSR.
5. Справа постоянный «Журнал Live» с событиями выбранной личной тренировки.
6. Журнал получает события из get_tracker_live_events.php и фильтрует их
   по live_session_id / player_id.
7. В журнале есть счётчики: все, красные, GPS, спринты, ускорения,
   торможения, 30+ км/ч.
8. Нажатие на событие автоматически включает «Карта» и подсвечивает
   соответствующую точку маршрута.
9. Режим «Просмотр момента» не останавливает текущую Live-запись.
10. Кнопка «В LIVE» снимает выбранный момент и возвращает текущий режим.
11. На узком планшете журнал переносится под рабочую область; на широком
    планшете остаётся справа.
12. Существующий календарь, обзор, сравнение и командный Live не менялись.

Сервер:
Используется уже установленный endpoint get_tracker_live_events.php.
Новый PHP для этой версии не требуется.
