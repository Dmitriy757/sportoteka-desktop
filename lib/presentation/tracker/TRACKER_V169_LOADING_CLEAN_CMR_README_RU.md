# SPORTOTEKA Tracker V169 — загрузка аналитики + чистый CMR layout

Дата: 20.08.2026
База: V168 CMR NAV RESTORE.

## Что исправлено

### 1. Бесконечная загрузка на 24%
В V168 вкладки «Локомоторика», «Механика», «Микроцикл», «ИИ-анализ», «Отчёты» и «Офлайн GPS» сначала ожидали общий тяжелый Analytics Bundle (GPS + Polar + heatmap), хотя затем использовали собственный экран отчета. Если один GPS endpoint не отвечал, интерфейс навсегда оставался на «Сессии загружены · 24%».

V169 разделяет загрузку:
- для report-вкладок после получения списка сессий тяжелый GPS/Polar bundle больше не ожидается;
- переключение на report-вкладку получает отдельный `report-lite` request key, поэтому не наследует зависший Future от «Обзора»;
- GPS, Polar, heatmap, dashboard и sessions получили timeout + fallback;
- для нескольких игроков GPS timeout применяется отдельно к каждому session row, поэтому один зависший датчик не блокирует остальных;
- Personal Ghost и fallback пульса также ограничены timeout.

### 2. Убрана лишняя шапка правого блока
В V168 над правой рабочей областью повторно выводилось название внутреннего раздела: «Обзор», «Механика» и т.д.

В V169 эта служебная шапка удалена. Название уже видно в левом CMR-подменю, поэтому справа сразу начинается рабочее содержимое — ближе к `cmr_club_roster_panel`.

### 3. Убраны явные дубли внутри подменю
- Из «Датчики» удален повторный пункт «Поле и калибровка».
- Настройки теперь владеют одним пунктом «Карта и поле».
- В «Основных настройках» убраны повторные переходы на «Устройства / Поле / Аналитика / История», потому что эти разделы уже доступны через левую CMR-навигацию.
- Убран дублирующий блок «Быстрые действия» из основного экрана настроек.
- Оставлено только техническое действие «Сбросить все GPS».

## Что не менялось
- V165/V168 Auto Recovery полного матча.
- Live Priority и возможность стартовать следующую сессию во время recovery.
- выбор сессии в левом CMR-блоке;
- Локомоторика / Механика / Микроцикл / ИИ / Отчёты;
- BLE lifecycle/GATT recovery правки предыдущих версий.

## Проверка после установки
1. Аналитика -> Выбор сессии -> Механика: экран должен открыться без зависания на 24%.
2. Переключить Механика -> Локомоторика -> Микроцикл: повторной тяжелой GPS-загрузки быть не должно.
3. Открыть Обзор/Карту: при зависшем endpoint максимум через несколько секунд экран продолжит работу с доступными данными вместо бесконечного loader.
4. Проверить, что над правой областью больше нет второй шапки «Обзор / Механика ...».
5. Датчики: отдельного дублирующего пункта «Поле и калибровка» больше нет.
6. Настройки: «Карта и поле» находится в одном месте — в левом подменю.
