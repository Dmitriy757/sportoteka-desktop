# V208 — плавное движение игроков на Live-карте

Изменения:
- точки игроков на Flutter-поле больше не перескакивают мгновенно между GPS-пакетами;
- визуальная позиция интерполируется ~780 мс через smoothstep;
- реальные GPS-координаты, дистанция, скорость и серверные данные не изменяются — сглаживание только визуальное;
- аватары игроков на поле и в расширенной Live-карте используют такую же более плавную анимацию;
- на 2ГИС и спутниковом слое HtmlMarker/Leaflet marker двигается через requestAnimationFrame;
- follow-камера 2ГИС/спутника стала мягче;
- во время replay/ручного просмотра Flutter-поля визуальная интерполяция отключена, чтобы показывать точный выбранный момент;
- при старте новой Live-сессии кэш визуального движения очищается.

Основные изменённые файлы:
- tracker_live_panel.dart
- widgets/tracker_2gis_map_layer.dart
