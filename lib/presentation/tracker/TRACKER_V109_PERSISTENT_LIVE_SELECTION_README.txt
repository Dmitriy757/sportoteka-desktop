SPORTOTEKA TRACKER V109

Changes from V108:
- Live monitor player selection is persisted per club/team while navigating between Tracker screens.
- Removed the previous 12-card practical limit for normal team sizes (limit raised to 32).
- Manually selected players remain eligible for Live cards even when GPS/Polar is not currently online.
- Right-side Live player table now shows a small avatar before the surname.
- GPS and cardio status icons are shown next to each player's name:
  green GPS = BLE GPS connected, orange GPS = GPS assigned, grey = no GPS;
  red heart = fresh cardio data, orange heart = cardio assigned, grey = no cardio.
- Selection persistence is updated on add/remove/focus/clear operations.
