# Tracker V181 — Обзор: два блока строго рядом

Изменение относительно V180:

- в desktop/tablet режиме «Радар выбранной сессии» и «Командная сводка» теперь **всегда расположены рядом в одной строке**;
- убран breakpoint, из-за которого при ширине менее 1120 px эти два блока становились друг под другом;
- оба основных блока получают одинаковую ширину 50/50;
- телефонный режим (<720 px) остаётся отдельным адаптивным интерфейсом;
- встроенный «Рейтинг дня» по-прежнему открывается внутри окна Tracker справа и не возвращает основные блоки в вертикальную колонку;
- все изменения V180 сохранены: без мини-теплокарты, CMR-точки, уменьшенные иконки, мягкие фоновые секции.
