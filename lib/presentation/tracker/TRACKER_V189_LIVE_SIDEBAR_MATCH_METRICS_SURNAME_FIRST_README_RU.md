# Tracker V189 — Live CMR menu + полный набор метрик матча

Изменения:
- desktop/tablet-wide Live (от ~980 px) получил левое CMR-меню;
- верхняя дублирующая лента игроков на desktop убрана, карта получила больше высоты;
- в меню доступны «Поле Live», «Игроки», «Все карточки», «Журнал», «Разбор Live», «Настройка Live»;
- добавлен быстрый список игроков слева с online-скоростью и дистанцией;
- «Все карточки» из меню автоматически собирает весь доступный состав (до 32) и сразу открывает полноэкранную сетку;
- в полноэкранных Live-карточках теперь 12 показателей: дистанция, текущая/максимальная скорость, пульс, спринты, HIR, ускорения, торможения, повороты, общее время, нагрузка и взрывные действия;
- выбор игрока слева сразу фокусирует его Live-данные справа;
- интерфейс нового меню использует AppTypography/_OFText, чтобы шрифт совпадал с CMR;
- в полном разборе матча справа добавлена компактная сетка Live-показателей: дистанция, средняя/максимальная скорость, время, спринты, HIR, ускорения, торможения, повороты, нагрузка, взрывные действия, усталость;
- максимум в заголовке графика полного матча теперь берётся из активного match-inspector, а не из локальной смешанной дорожки;
- фамилия теперь формируется первой из структурированных first_name/last_name в TrackerPlayerOption, а старые session player_name уступают данным состава: верхние карточки показывают формат «Фамилия И.».

Логика BLE/GPS/Polar, запись Live и серверные сессии не изменялись.
