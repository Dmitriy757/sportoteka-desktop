SPORTOTEKA TRACKER V132 — PERSONAL LIVE TEAM GRID

Что изменено в разделе «Личные тренировки → Live» тренера:

1. Live личной тренировки теперь принудительно использует двухколоночную планшетную сетку уже от 640 логических px, поэтому на iPad/планшете правая панель больше не уезжает вниз из-за devicePixelRatio.
2. Левая часть = 66%, правая = 34%, одинаковая высота — как в командном Live.
3. Слева единый блок «Карта / Пульс».
4. Под картой/пульсом: одна строка «Прямой эфир / Просмотр момента» и одна компактная KPI-полоса: дистанция, скорость, максимум, спринты, ЧСС, нагрузка.
5. Справа единая панель с переключением «Данные / Журнал».
6. Журнал показывает события только выбранной личной Live-сессии; красные события имеют счётчик на вкладке.
7. Нажатие события переводит левую часть в карту, подсвечивает точку и включает просмотр момента. «В LIVE» возвращает к текущему состоянию.
8. Вложенный заголовок «Журнал Live» убран, чтобы справа не было двойной шапки.
9. На телефоне (<640 логических px) блоки по-прежнему безопасно складываются вертикально.
