SPORTOTEKA TRACKER — Flagship V104
Основа: пользовательский tracker 11(3).zip
Дата: 2026-08-12

Основные изменения:
- LIVE на планшете больше не разворачивается автоматически. Полноэкранный режим только по кнопке разворота; закрытие возвращает обычный workspace.
- При выборе игрока подробности показываются справа, кнопка «Все игроки» мгновенно возвращает live-таблицу.
- LIVE-таблица уплотнена: метрики обозначены иконками, строки без лишних вертикальных/горизонтальных обводок, активный игрок подсвечивается фоном.
- Карта LIVE занимает весь свой блок без внутренних полей/AspectRatio; KPI под картой уменьшены и уплотнены.
- LIVE/Игроки/Поле визуально приближены к CMR Trainers: светлые плоскости, минимум рамок, мягкая зелёная подсветка состояния и только необходимые разделители.
- В карточках игроков активное состояние — фон + аккуратное нижнее подчёркивание вместо тяжёлой рамки.
- Поле/калибровка уплотнены: убраны внешние поля и часть декоративных границ.
- Аналитика: для тяжёлых разделов «Локомоторика», «Механика», «Микроцикл», «Отчёты» добавлена верхняя полоска загрузки с процентом.
- Подробный отчёт/сессия: вместо одиночного spinner используется верхняя progress-панель с процентом; прежнее содержимое остаётся видимым при повторной загрузке там, где это возможно.

Важно:
- Серверные PHP/API, BLE-протокол и форматы данных этим проходом не менялись.
- Flutter SDK в среде сборки архива отсутствовал, поэтому flutter analyze/build здесь не запускались.
