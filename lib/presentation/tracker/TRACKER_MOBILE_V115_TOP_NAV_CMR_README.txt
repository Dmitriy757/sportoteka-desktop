TRACKER MOBILE V115 — TOP NAV / CMR MOBILE

Основа: актуальный tracker 13(7).zip, в котором уже присутствуют V112–V114.

Основные изменения:
1. Нижний Dock Sportoteka на мобильном НЕ перекрывается Tracker.
2. Root Overlay для мобильного Tracker отключён: Tracker работает внутри Club Workspace.
3. Старое нижнее меню Tracker больше не используется.
4. Навигация Tracker перенесена наверх:
   LIVE / Игроки / Аналитика / Датчики / Ещё.
   Активный пункт — мягкий фон + маленькая зелёная точка.
5. В «Ещё»: Поле / Личные / Настройки.
6. Верхняя шапка Tracker уплотнена под стиль CMR Trainers.
7. Зарезервирована нижняя зона под внешний Dock Sportoteka, чтобы контент не перекрывался.
8. Мобильный экран игроков переработан: 2 колонки, фото, полное имя, позиция, номер, GPS/HR.
   Выделение — только мягкий фон + нижний зелёный акцент, без тяжёлых рамок.
9. Мобильный экран устройств переведён на более строгие CMR-состояния: активный GPS/Polar без сплошной зелёной заливки.
10. Стартовый выбор Командный/Личный Live приведён к нейтральным CMR-поверхностям; отдельная «История» из мобильного стартового экрана убрана — история доступна через Аналитику.
11. Все существующие Live/BLE/GPS/Polar/API функции сохранены.
12. Исправления V114 (переход из Live к устройствам конкретного игрока) сохранены.
