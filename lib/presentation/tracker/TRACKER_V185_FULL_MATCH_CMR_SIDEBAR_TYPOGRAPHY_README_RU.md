# Tracker V185 — полный разбор матча

Изменения в `widgets/tracker_action_analytics_suite.dart`:

- Для полного окна разбора матча на desktop (ширина от 1180 px) добавлено левое меню в том же CMR-стиле, что и меню карты аналитики.
- В левое меню перенесены: Маршрут, Тепло, Матч/Запись, 2D/3D PRO, Метки, Разбор, HUD, Ghost (личный режим), Пит-уолл, Точки, Поле, Карта 2ГИС, Спутник, ИИ и Видео.
- Внизу меню добавлено `К карте аналитики`: оно закрывает полный разбор и возвращает к карте, не отправляя в список сессий.
- Верхняя панель на desktop больше не дублирует инструменты карты. Сверху остаются контекст сессии, игроки и компактный KPI-ряд.
- Панель рисования/разбора появляется только когда включён режим `Разбор`.
- HUD в полном разборе теперь выключен по умолчанию, чтобы подписи игроков не накладывались друг на друга; его можно включить из левого меню.
- Подправлена типографика полного окна: карточки игроков, KPI, пороги, правая панель `Скорость + кардио`, журнал, транспорт воспроизведения, вкладки и подписи событий используют более единый `_AText/AppTypography`.
- Слегка увеличены размеры ключевых текстов и карточек игроков для читаемости на большом экране.
- На ширине меньше 1180 px оставлено прежнее компактное поведение без нового desktop-sidebar.

Проверка: выполнена структурная проверка файла и баланс скобок. В текущем окружении Dart/Flutter SDK отсутствует, поэтому `flutter analyze` здесь не запускался.
