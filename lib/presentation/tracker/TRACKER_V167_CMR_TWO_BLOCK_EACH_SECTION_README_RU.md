# SPORTOTEKA Tracker V167 — CMR: два внутренних блока в каждом разделе

Дата: 2026-08-20
База: V166 + сохранённая логика V165 Auto Recovery / Live Priority.

## Что исправлено относительно V166

В V166 была неверно понята композиция CMR: был изменён глобальный левый rail и добавлена контекстная панель справа. В V167 глобальное меню Tracker возвращено к прежнему виду, а двухблочная CMR-структура перенесена ВНУТРЬ каждого рабочего раздела.

На планшете/ПК каждый из пяти разделов теперь имеет одну и ту же структуру:

1. СЛЕВА — внутреннее подменю раздела, фильтры/выбор режима и краткие статусы.
2. СПРАВА — развёрнутая рабочая область выбранного подпункта.

Разделение включается при ширине рабочей области >= 900 px. На телефоне сохраняется прежняя мобильная компоновка.

## 1. Аналитика

Левый блок:
- Обзор
- Карта
- Скорость
- Пульс
- Команда
- Готовность
- Отчёты
- Офлайн GPS

Правый блок:
- существующая полноценная TrackerActionAnalyticsSuite;
- выбранный пункт слева реально переключает tab через initialTab/initialTabSignal;
- на desktop/tablet внутренняя верхняя строка вкладок аналитики скрывается, чтобы не было дублирования навигации;
- мобильная аналитика сохраняет собственную навигацию.

## 2. Датчики

Левый блок:
- GPS-трекеры
- Polar
- Игроки
- Восстановление GPS
- Поле и калибровка

Правый блок:
- GPS/Polar — существующий workspace устройств;
- Игроки — состав для назначения датчиков;
- Восстановление GPS — отдельный CMR-экран состояния автоматической догрузки полного матча;
- Поле — существующий экран калибровки.

GPS/Polar подпункты синхронизированы с `_deviceWorkspaceTab`.

## 3. Игроки

Левый блок:
- Состав
- Аналитика игрока
- Датчики игрока
- Личные тренировки

Правый блок открывает соответствующий существующий рабочий модуль, при этом глобальный раздел остаётся «Игроки».

## 4. Личная тренировка

Левый блок:
- Сессии
- Аналитика
- Датчики
- Игрок
- Live

Правый блок:
- история личных сессий;
- аналитика выбранного игрока;
- датчики;
- состав/выбор игрока;
- отдельный экран готовности к Live.

## 5. Настройки

Левый блок:
- Основные
- Поле
- Устройства
- Восстановление
- Диагностика

Правый блок показывает соответствующий полноценный экран.

## CMR-дизайн

- Глобальное меню Tracker НЕ заменяется точками — восстановлен прежний rail V165.
- Фирменные точки SPORTOTEKA используются только как акцент внутри разделов.
- Белый фон, мягкий серый workspace, радиусы 20 / 12 / 11 px.
- Один тонкий разделитель между левым внутренним блоком и правой рабочей областью.
- Меньше декоративных иконок в новом подменю: навигация строится на тексте и фирменной точке состояния.
- Внизу левого внутреннего блока всегда видны GPS / Polar / Live / Recovery.

## Auto Recovery V165 сохранён

Не удалены изменения V165:
- автоматическая догрузка полного GPS-файла после Stop;
- recovery не блокирует запуск новой Live-сессии;
- во время новой Live BLE recovery ставится на паузу;
- pending/waiting задачи сохраняются;
- после Stop recovery продолжает работу;
- после успешной догрузки обновляется data revision аналитики.

## Изменённые файлы

- `tracker/widgets/player_training_notifications_panel.dart` сохранён из V166 (синхронизация выбранного игрока + CMR palette).

## Проверка

Архив проверен через `unzip -t`.
В изменённых Dart-файлах выполнена лексическая проверка баланса (), {}, [] с исключением строк и комментариев.
Flutter SDK в среде сборки отсутствует, поэтому окончательный `flutter analyze` / Xcode build нужно запустить в основном проекте.
