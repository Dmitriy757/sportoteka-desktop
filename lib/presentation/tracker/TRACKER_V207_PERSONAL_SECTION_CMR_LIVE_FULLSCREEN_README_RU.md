# V207 — Personal section rebuilt around the shared CMR shell

- При входе в «Личные тренировки» больше нет отдельного root fullscreen.
- Нижний Dock Sportoteka остаётся видимым.
- Левое меню — тот же `_CmrSectionNavigationPane`, что у Аналитики:
  одинаковая ширина, Inter, размеры, отступы и active-state.
- Пункты: Сессии / Live / События / Календарь / Сравнение /
  Аналитика / Датчики / Игрок.
- События и Календарь теперь открываются внутри этого же CMR shell.
- У календаря в CMR режиме скрыта дублирующая внутренняя шапка.
- Personal Live становится root fullscreen только если вкладка Live открыта
  и реально есть активная личная тренировка.
- Закрытие Personal Live возвращает в «Личные → Сессии» и возвращает нижний Dock.
- Полноэкранный V206 Live (игроки, Поле/Карта/Спутник, 2D/3D PRO,
  Журнал/Скорость/Кардио) сохранён.

Дополнение:
- mobile/tablet переход в Personal также больше не создаёт fullscreen overlay;
- fullscreen Personal Live не закрывается на первом кадре, пока его собственный
  API poll ещё загружает active Live.
