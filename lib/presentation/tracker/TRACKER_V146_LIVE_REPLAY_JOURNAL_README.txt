SPORTOTEKA TRACKER V146 — LIVE REPLAY JOURNAL
16.08.2026

Что изменено
============

1. Полноэкранная аналитика завершённой тренировки получила Live Replay Journal.

2. В режиме Матч / Запись справа теперь переключатель:
   - Игроки
   - Журнал
   По структуре и поведению журнал повторяет Live-панель.

3. Источник журнала двухуровневый:
   A) сначала приложение пытается получить реально сохранённые Live events через
      существующий get_tracker_live_events.php;
   B) если событие не сохранилось или старая тренировка была без Live-журнала,
      событие восстанавливается из GPS + Polar.

4. Восстанавливаются полезные моменты:
   - спринт;
   - HIR / высокая интенсивность;
   - ускорение;
   - торможение;
   - поворот;
   - остановка;
   - пауза / разрыв GPS по отсутствию новых точек внутри одного player stream.

5. Кардио связано с GPS-событием:
   - HR на старте;
   - HR peak;
   - HR через 30 секунд;
   - recovery delta.
   Эти данные также передаются в Спортотека ИИ.

6. Нажатие строки журнала:
   - переводит общий replay-таймлайн на событие;
   - фиксирует карту на моменте;
   - подсвечивает соответствующую точку;
   - НЕ закрывает журнал справа.

7. Метки на поле очищены от визуального шума:
   - больше не показывается до 160 одинаковых точек;
   - на поле остаётся ограниченный набор наиболее важных Replay-маркеров;
   - оранжевый = значимый момент;
   - красный = приоритетный момент;
   - маленький зелёный центр = реальное сохранённое Live-событие;
   - маленькая красная дополнительная точка = найден синхронный Polar/HR.

8. В обычном маршруте полноэкранной аналитики при фильтре «Все» отключены
   кружки на каждой GPS-точке. Сам маршрут остаётся, а отдельно поверх него
   рисуются чистые метки Replay-журнала. При выборе специального фильтра
   (спринт/поворот/ускорение и т.п.) технические точки снова показываются.

9. Добавлен cache Replay-журнала, чтобы playback на 1x/2x/4x не пересчитывал
   сотни GPS/HR событий каждые 200 мс.

10. Спортотека ИИ дополнительно получает:
    - replay_journal_source;
    - replay_journal_events;
    - gps_hr_linked_moments.

Сервер
======
Обязательных изменений PHP/БД для запуска этой версии нет.
Если get_tracker_live_events.php доступен и содержит архивные события — они
будут использованы. Если endpoint старый/недоступен/не содержит старую сессию,
аналитика автоматически строит Replay-журнал из сохранённых GPS + Polar.
