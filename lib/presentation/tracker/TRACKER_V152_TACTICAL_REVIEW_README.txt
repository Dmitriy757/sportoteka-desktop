SPORTOTEKA TRACKER V152 — TACTICAL REVIEW / TRAINING GRAPHICS OVERLAY
=====================================================================

Что добавлено
-------------
1. В полноэкранной аналитике карты появилась кнопка «Разбор».
2. При входе в «Разбор» Replay автоматически ставится на паузу (freeze frame).
3. Поверх существующей карты Tracker подключён отдельный Training Graphics overlay:
   - выбор и перетаскивание объектов;
   - свободное рисование;
   - стрелка;
   - круг;
   - зона;
   - текст;
   - заметка эпизода с текущим временем Replay;
   - объекты: игрок, мяч, конус;
   - Undo / Redo;
   - удаление выбранного;
   - очистка разбора.
4. Рисунки сохраняются в логических координатах поля 1050x680, поэтому не зависят
   от размера телефона / планшета / Mac.
5. Overlay находится ВНУТРИ _AnalyticsPitchPerspective, поэтому в 3D рисунки
   наклоняются и вращаются вместе с полем.
6. Overlay построен через AnimatedBuilder с child-кэшем: изменение стрелки или
   объекта не перестраивает тяжёлый GPS painter и не возвращает проблему тормозов 3D.
7. Разбор привязан к ключу team/session/start и сохраняется в session cache на время
   работы приложения. Повторное открытие полноэкранного окна этой же сессии в рамках
   текущего запуска восстанавливает рисунки.
8. Все TgElement текущего разбора передаются в telemetry AI payload как
   tactical_review_annotations + tactical_review_count.

Новые/изменённые файлы
-----------------------
tracker/widgets/tracker_action_analytics_suite.dart
training_graphics/tg_analytics_overlay.dart

Важно
-----
Текущая V152 не добавляет новый серверный API и таблицы БД. Поэтому постоянное
хранение заметок между перезапусками приложения пока не включено: это специально
не добавлялось без согласованного backend endpoint, чтобы не ломать текущий API.
Архитектура overlay уже сериализует TgElement через toJson/fromJson, поэтому следующий
шаг — серверное сохранение разбора без переделки UI/рисования.
