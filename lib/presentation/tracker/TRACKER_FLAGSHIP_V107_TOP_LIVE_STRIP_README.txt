SPORTOTEKA TRACKER — V107

Изменения Live ПК/планшет:
- Лента выбранных игроков перенесена над всей рабочей областью Live: от карты до правой панели.
- Игрок добавляется в верхнюю ленту кнопкой «+» в таблице Live.
- Карточка игрока в верхней ленте открывает его подробные данные; крестик на карточке убирает игрока из ленты.
- Кнопка «12 карточек» из основной Live-ленты убрана: все выбранные карточки доступны горизонтальной прокруткой.
- Дублирующая строка «LIVE · Карта / N в окнах / N online» над картой убрана.
- Кнопки «Трек / Тепло / Нагрузка» убраны из шапки карты.
- В правом верхнем углу карты добавлено раскрывающееся меню «…» со слоями Трек / Тепло / Нагрузка и отметкой активных слоёв.
- Карта получила дополнительную вертикальную площадь за счёт удаления отдельной шапки.

Основная BLE/GPS/Polar/API логика V106 сохранена.
