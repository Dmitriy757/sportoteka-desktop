# Tracker V191 — журнал в правом блоке + меню на планшетах

Изменения поверх V190 / tracker 12.7:

1. В полном повторе матча журнал больше не накладывается поверх футбольного поля.
2. При открытии «Журнал» весь правый аналитический блок переключается на отдельный прокручиваемый журнал.
3. Закрытие журнала возвращает обычную правую панель с графиком, KPI и игроками.
4. Убрана тень журнала, которая визуально заходила на край поля.
5. Левое CMR-меню полного разбора теперь сохраняется на планшетах от 720 px, а не только от 1180 px.
6. На компактных планшетах ширина левого меню автоматически уменьшается: 168 / 184 / 200 / 220 / 236 px в зависимости от доступной ширины.
7. Телефонный режим (<720 px) оставлен без постоянного левого меню.

Основной изменённый файл:
- widgets/tracker_action_analytics_suite.dart
