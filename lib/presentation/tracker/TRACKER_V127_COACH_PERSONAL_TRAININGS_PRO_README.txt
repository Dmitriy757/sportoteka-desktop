SPORTOTEKA TRACKER V127 — COACH PERSONAL TRAININGS PRO
=======================================================

Что изменено в командном разделе «Личные тренировки» тренера:

1. Новый тренерский центр личных тренировок
   - общая шапка команды;
   - онлайн / завершено сегодня / Polar / GPS / внимание тренера;
   - быстрый выбор любого игрока команды или режима «Вся команда».

2. Пять режимов
   - Обзор;
   - Live;
   - События;
   - Сравнение;
   - Календарь.

3. Обзор тренера
   - текущая личная тренировка выбранного игрока;
   - справа блок «Внимание тренера»;
   - контроль полноты GPS/Polar;
   - последние личные тренировки;
   - быстрый переход в подробный Live и аналитику.

4. Расширенные Live-показатели игрока
   - начало;
   - длительность;
   - дистанция;
   - текущая и максимальная скорость;
   - пульс;
   - спринты;
   - ускорения;
   - торможения;
   - взрывные действия;
   - HSR;
   - нагрузка;
   - AI-индекс;
   - график пульса;
   - GPS/маршрут;
   - зоны интенсивности, бег и ходьба.

5. Внимание тренера
   Автоматические спортивные сигналы по доступным данным:
   - высокая текущая интенсивность по пульсу;
   - высокая внешняя нагрузка;
   - пиковый AI-индекс;
   - длительная личная сессия;
   - отсутствие актуального Polar/GPS при заявленном источнике;
   - заметное падение максимальной скорости относительно предыдущей личной тренировки.

   Эти сигналы являются спортивными ориентирами интерфейса, не медицинской диагностикой.

6. Сравнение
   - последняя тренировка ↔ предыдущая;
   - дистанция;
   - максимальная скорость;
   - нагрузка;
   - средний пульс;
   - спринты;
   - длительность;
   - командный экран динамики по всем игрокам.

7. Календарь
   - личные тренировки всей команды или выбранного игрока;
   - выбор даты и сессии;
   - переход в существующую аналитику Tracker.

8. Сервер
   Новых PHP endpoint для этой версии не требуется. Используются уже существующие:
   player_get_live_state.php
   player_get_training_notifications.php
   player_get_session_heart_rate.php
   player_get_sessions.php
   и текущие Tracker analytics endpoints.

Изменённые основные файлы:
- tracker/widgets/player_training_notifications_panel.dart
- tracker/screens/tracker_match_workspace_screen.dart

Сборка Flutter в среде подготовки архива недоступна. Файлы проверены на структурный баланс Dart-скобок.
