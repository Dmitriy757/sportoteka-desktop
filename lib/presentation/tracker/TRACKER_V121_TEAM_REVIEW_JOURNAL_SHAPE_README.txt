Sportoteka Tracker V121 — Team Live Review / Player Journal / Team Shape

Изменения:
1. Общий Live: под картой добавлена временная линия «ПРЯМОЙ ЭФИР».
   - красные/оранжевые моменты отображаются точками;
   - нажатие на момент возвращает всю командную карту к этому времени;
   - Live-сессия и запись продолжаются в фоне;
   - кнопка «В LIVE» возвращает к текущим координатам;
   - можно нажимать по самой линии времени для просмотра истории, когда локальная GPS-история доступна.

2. «Все карточки» -> «Подробнее» игрока:
   - экран разделён на 3 рабочих блока: поле / пульс и нагрузка / лента-журнал;
   - журнал показывает события только выбранного игрока;
   - нажатие на событие переносит поле к точке этого момента;
   - нижняя Live-линия игрока сохранена.

3. Live-карта:
   - слой «Аватары» можно включать/выключать;
   - слой «Связи игроков» повторяет командную форму из аналитики (convex hull / тактический контур);
   - связи строятся только по свежим GPS-позициям и не тянутся к давно потерянному игроку;
   - в режиме командной карты доступны быстрые кнопки «Аватар» и «Связи».

4. Backend:
   - новых PHP-изменений для V121 не требуется;
   - используется PHP V120 (get_tracker_live_events.php + save_tracker_live_point.php).

Примечание: в этой среде Flutter/Dart SDK не установлен, поэтому flutter build здесь не запускался.
Файл дополнительно проверен на баланс скобок/структуру после изменений.
