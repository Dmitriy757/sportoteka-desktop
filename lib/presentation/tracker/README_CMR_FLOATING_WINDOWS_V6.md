# Sportoteka Tracker — CMR Floating Windows V6

Изменения:
- окна Live-блоков теперь можно перетаскивать мышью за верхнюю панель;
- кнопки закрыть/свернуть/развернуть сделаны серыми круглыми, как в CMR/Windows 11 стиле;
- убраны цветные macOS-точки в плавающих окнах;
- иконки в круглых плашках сделаны мягко-серыми, без чёрного визуального веса;
- окно сохраняет логику свернуть/развернуть/закрыть;
- при открытии нового блока позиция сбрасывается в центр, далее окно можно свободно двигать внутри рабочей области.
