# TRACKER V170 — CMR layout cleanup

Дата: 20.08.2026
База: V169 Loading / CMR Clean

## Что исправлено

### 1. Analytics — только одна линия загрузки
- Удалён искусственный второй progress для вкладок «Локомоторика», «Механика», «Микроцикл».
- Остаётся только реальный bundle progress.
- Полоса стала тоньше и компактнее: без второй нижней линии/рамки.
- V169 timeout/fallback и lightweight-загрузка отчётных вкладок сохранены.

### 2. Analytics — обзор собран в более ровную CMR-сетку
- KPI остаются сверху.
- На широком экране: «Командная сводка» / «Радар» / «Рейтинги» выровнены по общей высоте.
- На средней ширине рейтинги уходят во второй ряд, чтобы три колонки не сжимались.
- Карточки командной сводки компактнее и раньше переходят в 2 колонки.
- Общие `_Panel` получили более лёгкую рамку/тень и одинаковую компактную шапку.

### 3. Датчики — убраны дубли и тяжёлые рамки
- В основном разделе «Датчики» GPS/Polar выбираются левым внутренним CMR-меню, поэтому второй набор вкладок «Трекеры / Polar» сверху больше не дублируется.
- Верхняя строка стала одной плоской CMR-панелью.
- Оставлены: количество устройств, «Подключение / Назначенные», обновление и одно контекстное действие «Найти GPS / Найти Polar».
- Основная рабочая область больше не завернута в отдельную толстую карточку.
- Нижние действия оформлены компактными текстовыми кнопками с фирменной точкой: Автоназначение / Архив / Восстановить GPS / Сброс BLE.

### 4. Поле — убраны дублирующие действия
- «Новое поле» и «Параметры» теперь находятся только в левом блоке списка полей.
- «Убрать поле» также перенесено в левый блок.
- В общей верхней шапке оставлены только действия текущей калибровки: GPS / Перекалибровать / Сохранить / Live.
- Если поле уже сохранено, показывается «Открыть Live» вместо повторного «Сохранить и Live».

### 5. Поле — правая часть ближе к CMR Roster
- Убрана дополнительная внешняя `_DarkCard` вокруг калибровки.
- Правая область теперь: плоская белая поверхность → компактная шапка → один разделитель → статусы → карта → координаты A/B/C/D.
- Уменьшены лишние вертикальные промежутки.

### 6. Шапки
- `_WorkspaceFlatHeader` приведён к фиксированной высоте 56 px.
- Заголовок левого внутреннего CMR-блока получил фиксированную высоту 60 px.
- Разделители сделаны тоньше и одинаковее.

## Что не менялось
- V165 Auto Recovery полного матча.
- Live Priority: новую сессию можно запускать при очереди recovery.
- BLE lifecycle fix / защита закрытых StreamController.
- V169 timeout/fallback аналитики.
- Список аналитических вкладок и выбор сессии.
- Серверные API и структура БД.

## Быстрый тест
1. Аналитика → Обзор: убедиться, что сверху максимум одна линия загрузки.
2. Аналитика → Механика → Локомоторика: переключение без второй progress-полосы.
3. Датчики: в основном разделе не должно быть второго дублирующего «Трекеры / Polar» над рабочей областью.
4. Датчики: проверить GPS → Polar через левое подменю и «Найти GPS / Найти Polar».
5. Поле: «Новое / Параметры / Убрать» только слева; сверху только действия калибровки.
6. Поле: проверить A/B/C/D, перекалибровку и открытие Live.
