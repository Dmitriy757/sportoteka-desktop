# Sportoteka Tracker — CMR unified layout

Что изменено:

1. Трекер внутри Club Workspace теперь рисует только одно внешнее окно — без вложенного "окна в окне".
2. Все вкладки используют единую светлую CMR/Windows 11 поверхность и тонкие разделители.
3. Добавлена общая кнопка разворота окна снизу справа, как в CMR Club Teams.
4. Live-поле получило приоритет по высоте: таблица сжата, поле лучше видно в обычном режиме.
5. Убран декоративный таймлайн с фиктивным временем. Теперь таймлайн строится по реальному старту Live/точкам GPS и показывает реальные маркеры нагрузки: HIR, VHIR, SPR, ACC, DEC.
6. Отчёт тренировки может открываться во встроенном режиме без собственного Scaffold/SafeArea.

Файлы для замены находятся в тех же путях внутри архива.
