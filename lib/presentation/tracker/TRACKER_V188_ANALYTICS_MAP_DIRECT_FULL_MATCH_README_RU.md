# Tracker V188 — Аналитика → Карта сразу открывает полный матч

Изменена desktop-навигация CMR Analytics.

## Новая логика

1. В левом меню аналитики нажать **«Карта»**.
2. Промежуточный экран карты и его отдельное боковое меню больше не показываются.
3. Сразу открывается **полный разбор матча / повтор матча** (`initialMatchMode = true`).
4. В полном матче остаётся собственное левое меню инструментов: Маршрут, Тепло, Матч, 2D/3D, Метки, Разбор, HUD, Пит-уолл, Точки, подложки, ИИ, Видео.
5. Нижняя кнопка **«К карте аналитики»** закрывает полный матч и возвращает в **«Обзор»** основного меню аналитики.
6. Крестик полного матча при таком прямом входе также возвращает в **«Обзор»**, чтобы не оставлять скрытый промежуточный экран карты.

## Изменённые файлы

- `screens/tracker_match_workspace_screen.dart`
- `widgets/tracker_action_analytics_suite.dart`

## Примечание

Мобильную навигацию этим изменением не трогали. Прямой переход включён для CMR desktop (`>= 1012 px`).
