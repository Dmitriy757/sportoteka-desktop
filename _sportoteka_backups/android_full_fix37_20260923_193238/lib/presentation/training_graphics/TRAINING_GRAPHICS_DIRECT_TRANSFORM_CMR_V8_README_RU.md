# Training Graphics v8 — прямое управление объектами + CMR/Tracker-панель

## Что изменено

### 1. Трансформация прямо на поле
После выбора объекта в режиме **«Выбор»** вокруг него появляется рабочая рамка:

- перетаскивание самого объекта — перемещение;
- четыре угловые ручки — увеличение/уменьшение;
- круглая ручка над рамкой — поворот;
- ручки остаются экранного размера и в 2D, и в 3D, поэтому ими удобно пользоваться мышью и пальцем;
- для нескольких выбранных объектов трансформация применяется к группе.

Поддержаны фигуры, игроки/объекты, текст, линии, кривые, зоны, волны, зигзаги, пружины и спирали.

### 2. Жесты на планшете
В режиме «Выбор»:

- один палец по объекту — перемещение;
- угловая ручка — масштаб;
- верхняя круглая ручка — поворот;
- два пальца **на выбранном объекте** — масштаб + поворот + перемещение;
- два пальца **вне выбранного объекта** — управление картой/камерой как раньше.

### 3. Понятное разделение «Объект / Точки»
Для кривых, волн, зигзагов, пружин и спиралей справа теперь два явных режима:

- **Объект** — перемещение, размер, поворот;
- **Точки** — изменение формы траектории по контрольным точкам.

При нажатии пункта **«Выбор»** в левом меню редактор автоматически выходит из режима точек и возвращает ручки трансформации объекта.

### 4. Правая панель в стиле Tracker / CMR

- серые контурные карточки убраны;
- группы настроек сделаны светлыми фоновыми баннерами `#F6F8F7`;
- активные состояния используют мягкий зелёный фон `#EFF8F2`;
- уменьшены радиусы и визуальный шум;
- панель больше не имеет тяжёлой наружной тени/рамки;
- шрифты и веса приведены ближе к Tracker Overview;
- слайдеры сделаны тоньше и компактнее;
- сверху добавлена короткая подсказка по управлению объектом.
