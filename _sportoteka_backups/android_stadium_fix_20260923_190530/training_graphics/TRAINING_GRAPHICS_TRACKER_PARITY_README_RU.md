# Training Graphics — унификация с Tracker

Обновление приводит основной редактор Training Graphics к тому же CMR-паттерну, который используется в карте/разборе Tracker.

## Что изменено

### 1. Левая панель как в Tracker
- desktop/tablet ширины: 232 / 262 / 286 / 306 px;
- те же принципы строки: иконка 24 px, заголовок ~10.6, подпись ~9.5, активный мягко-зелёный фон;
- инструменты перенесены в левую панель: выбор, объекты, линия, квадрат, круг, текст, кривая, волна, серия, тактика, слои, свойства;
- отдельный блок «Поле и камера»;
- undo/redo, вписать поле и переход к выбранному объекту находятся внизу;
- возврат «К меню тренировок» оформлен как нижняя CMR-карточка.

На узких экранах (< 920 px) панель автоматически переходит в компактный rail, чтобы не ломать мобильную компоновку.

### 2. Убрано дублирование инструментов
- на desktop/tablet нижняя полоса рисования больше не дублирует левое меню;
- на компактном мобильном режиме нижняя полоса сохранена;
- переключатель 2D/3D убран из верхней шапки — теперь он находится в едином левом меню, как в Tracker.

### 3. 3D PRO как в Tracker
- «3D PRO» / «2D» переключаются из левого меню;
- при включённом 3D появляется круговой джойстик справа снизу;
- горизонтальный drag вращает поле;
- вертикальный drag меняет наклон камеры;
- кнопки + / − меняют масштаб;
- кнопка центра и double tap по джойстику сбрасывают 3D-камеру;
- при 3D мини-карта скрывается, чтобы не конфликтовать с джойстиком;
- reset/fit теперь учитывает текущий 2D/3D режим.

### 4. Своя текстура поля
В левой панели добавлены:
- «Стандартное поле»;
- «Своя текстура»;
- регулировка наложения 10–100%.

Поддерживаются PNG/JPG/WEBP и другие изображения, которые возвращает системный image picker. Максимальный размер выбранного файла — 4 МБ (после base64 остаётся запас для типичных PHP-лимитов запроса).

Текстура сохраняется в JSON схемы в base64 и поэтому не зависит от локального пути на конкретном Mac/iPad. Старые схемы без этих полей продолжают открываться.

Новые JSON-поля:
- `custom_field_texture_base64`
- `custom_field_texture_name`
- `custom_field_texture_opacity`

Выбор/сброс текстуры участвует в Undo/Redo.

## Зависимость

Для системного выбора локальной картинки используется пакет `file_picker`.

Если он ещё не подключён в основном `pubspec.yaml`, выполните:

```bash
flutter pub add file_picker
```

Миграций БД/PHP для этого изменения не требуется, если JSON документа схемы уже хранится как достаточно большой TEXT/JSON/LONGTEXT. Для пользовательских изображений большого размера рекомендуется LONGTEXT/JSON и достаточный лимит тела HTTP-запроса.
