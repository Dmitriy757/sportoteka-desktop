# Training Graphics v6 — отдельное окно «Анимация»

Изменения относительно v5:

- постоянная нижняя панель «Анимация» убрана с карты;
- в левое CMR-меню добавлен пункт «Анимация»;
- по нажатию открывается отдельное правое окно;
- в окне доступны Play/Pause, прогресс, добавление/копирование/переименование/удаление шагов;
- объект для анимации, «Взять объект», «Привязать», «Очистить привязку» перенесены внутрь окна;
- маршруты текущего шага показываются внутри окна;
- на широком экране поле резервирует место справа и не оказывается под окном;
- на узком экране окно открывается поверх карты и закрывается крестиком или нажатием по фону;
- 3D-джойстик автоматически смещается влево от открытого окна;
- мини-карта и плавающая панель свойств скрываются на время открытого окна, чтобы не было наложений;
- после удаления нижней панели поле занимает больше полезной высоты;
- вся логика шагов/маршрутов/сохранения анимации сохранена.

Основные изменённые файлы:
- `training_graphics_screen.dart`
- `widgets/tg_left_toolbar.dart`

Версия `file_picker 11.0.3` и исправления v4/v5 сохранены.
