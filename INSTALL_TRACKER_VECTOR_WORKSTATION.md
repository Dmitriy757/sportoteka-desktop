# Sportoteka Tracker Vector Workstation

Заменить Flutter-файлы из `lib/presentation/tracker/`.

После замены:
```bash
flutter clean
flutter pub get
flutter run
```

Если дизайн не изменился:
1. проверьте, что заменён `lib/presentation/tracker/sportoteka_tracker_pro_screen.dart`;
2. удалите старое приложение с планшета;
3. установите заново.

В шапке должно быть написано: `Sportoteka Vector Tracker`.
